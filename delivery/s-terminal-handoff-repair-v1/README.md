# 失败后独立任务接续

固定镜像内已通过21项终态测试、4项可选依赖测试、933样本/2799分支在64/96/128并发配置下的真实bind/load，以及两套原生入口的8条协程路径。完整CPU验证1411秒，未调用模型。

已部署到两台主机。当前在途执行包保持不变；失败终态后的独立后继使用单独固定执行包。策略默认关闭，启用须配置有限任务白名单。核对旧进程退出、同boot/service、持有原guard、引擎空闲、原终态/flight归档与校验后才交接。未知请求保持原journal，不重发。正常接续已有实测；真实失败后的自动接续仍待运行事件验证。

此公开目录只提供源码与默认配置，内部路径已替换。真实数据、运行回执、tokenizer缓存、源manifest和凭据不公开；不能将源码副本当作已就绪的运行环境。执行与CPU评分、预部署异步；入口复用既有scheduler，未改模型镜像。
