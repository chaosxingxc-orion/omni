# 意图内槽位关系盘点

使用原锁定 60 意图、402 个槽位绑定定义，结合来源隔离与 clean-v5 后 5,795 条合法 TRAIN，扫描卡片对其他槽位的显式引用及规则措辞。没有使用开发集答案或测试集，也没有模型调用。

发现 50 个意图包含 267 条候选关系，其中 117 条有标注共存样本，219 条同时有 A-only 与 B-only 的正向证据。它们是后续共同区分知识的审阅索引，不是 267 个已证实冲突，也不是可以直接注入的规则。没有关系边不代表没有歧义；类型名同时是普通英文词时仍可能误匹配，需语义审阅。

输出保留每条关系的原卡句子、TRAIN 四状态计数和完整来源 ID。共存缺失不禁止共存，未标注不作可靠负例。后续按业务角色和已有设计审阅关系，再采用向量条件下的代表性与区分性选择示例，不能按 ID 取前三条当作最佳 few-shot。

这一步把规划范围从三个局部意图扩展到完整知识结构，不改变正在准备的清洗供给，不阻塞 NPU 准入。
