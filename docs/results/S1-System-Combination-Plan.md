# S1组合优化：召回约束下提高候选质量

用户目标：类型召回至少95%，同时提高准确率，不能把大量错误候选推给D。主线程负责综合多策略证据、选择受控组合和最终验证。

设候选配置ω=(知识K,消费策略R_policy,提示p,协议q)，模型θ冻结；G_i为gold类型集，Z_i为预测集。

R(ω)=Σ|G_i∩Z_i|/Σ|G_i|；P(ω)=Σ|G_i∩Z_i|/Σ|Z_i|；E(ω)=Σ|Z_i−G_i|/N。

第一层可行性：R(ω)>=0.95，报告配对置信区间和逐类退化、完整执行率；95%是用户目标，点估计达标与稳定泛化达标分开。
第二层：在可行方案中优先提高P、降低E，兼顾正样本完整覆盖、空样本正确率、每条额外候选p90/p95和时延/卡时。权重未被用户定义，不伪造单一加权总分；用Pareto比较与具体权衡报告。不能靠丢难例或全部输出刷分。

U作为高召回研究起点：TRAIN R97.7343/P17.9737、E4.3021，DEV未确认。U对直接supply恢复29丢14，净TP15、FP净增1480；旧减extra假说失败，但召回优先下仍有研究价值。U不是最终部署组合。

组合路径：
1. U完整知识/消费/语义提示冻结，先做空格分隔0/1协议，验证判决质量及输出成本，避免同时换知识混因果。
2. 审E/K/I/L与局部错例证据，选对准主要FN/FP类别且机制不同的改动。在U同parent上单项验证后才能声称可移植收益。
3. 主线程选择达到召回约束且去噪有效的组件，测组合后的真实效果。记录各单项差值及组合差值，检查互作：Δ_AB−Δ_A−Δ_B；未测项不填预期收益。
4. 固定配置在DEV1850确认，保全部类型/失败分母，不根据DEV反复调参；最终全量TEST验证与D实际消费质量在后续系统阶段完成。

诊断层：当前B778FN按正Fold分解：693全0、74仅选参考外、11保部分gold；U剩146FN需独立分析，不直接套B问题。FP归因需看实际音频/知识及参考语义，未确认不能称所有参考外都为幻觉。

CPU教师/编译/评分与NPU队列异步；保现有活任务，下一轮以U→binary优先，旧JSON DEV派发保持HOLD。子进程必须交完整Why/What/How、来源、配置、反例和测量结果；主线程不直接拼接未经实测的收益。

## 主线程组合决策更新

U全量TRAIN6681的召回97.7343%、精确率17.9737%，平均参考外标签4.3021/条。28742个参考外标签中28460出现在无gold类型的Fold，282出现在有gold类型的Fold。负Fold占请求90.45%；每Fold参考外事件率分别0.4710与0.0442。正Fold条件精确率95.71%仅供离线定位，不能当总体精确率，也不能按gold选择线上Fold。当前优先修复无关Fold的错误激活，同时保护正确类型命中。

E全量实验相对其直接供给基线：动态示例上限4降至1后，TP减少123、FP减少594，召回97.50%降至95.59%，精确率18.730%至18.764%，差值置信区间跨0。不能把全局减示例当作已有效的去噪组件加入U。

主线程选取下一轮机制，而非把所有策略叠加：
- 保留U作为高召回研究起点；空格二元输出作为独立协议实验，不能预先承诺精度收益。
- 优先准备“示例正支持片段显式呈现”，帮助区分当前语音证据与示例背景。保留原示例及来源，不要求目标词与示例字面相同，不把未标注当负证据。此项尚为设计，未测收益。
- 对有具体错例支持的槽位边界，用既有知识来源补充判别规则，不凭教师生成业务定义。此项尚未测收益。
- 静态示例分区与正支持片段属于相近消费机制，先比较再选；逐类型独立请求另做成本/机制对照，不默认更准确。

在共同冻结基座上分别验证后，主线程挑选互补组件做真实组合，记录恢复/丢失正确标签、删除/新增参考外标签，验证组合互作。目标R>=95%，同时提高P、降低每条及尾部多标，保护空样本判空与逐类覆盖；不把95%当成可随意损失正确标签的配额。TRAIN选方案后，固定DEV1850确认；未测组合不得宣称最优。
