# S1组合优化：召回约束下提高候选质量

用户目标：类型召回至少95%，同时提高准确率，不能把大量错误候选推给D。主线程负责综合多策略证据、选择受控组合和最终验证。

设候选配置ω=(知识K,消费策略R_policy,提示p,协议q)，模型θ冻结；G_i为gold类型集，Z_i为预测集。

R(ω)=Σ|G_i∩Z_i|/Σ|G_i|；P(ω)=Σ|G_i∩Z_i|/Σ|Z_i|；E(ω)=Σ|Z_i−G_i|/N。

第一层可行性：R(ω)>=0.95，报告配对置信区间和逐类退化、完整执行率；95%是用户目标，点估计达标与稳定泛化达标分开。
第二层：在可行方案中优先提高P、降低E，兼顾正样本完整覆盖、空样本正确率、每条额外候选p90/p95和时延/卡时。权重未被用户定义，不伪造单一加权总分；用Pareto比较与具体权衡报告。不能靠丢难例或全部输出刷分。

U作为高召回研究起点：TRAIN R97.7343/P17.9737、E4.3021，DEV未确认。U对直接supply恢复29丢14，净TP15、FP净增1480；旧减extra假说失败，但召回优先下仍有研究价值。U不是最终部署组合。

组合路径：
1. U完整知识/消费/语义提示冻结，先做空格分隔0/1协议，验证判决质量及输出成本，避免同时换知识混因果。
2. 审E/K/I/L与局部错例证据，选对准主要FN/FP类别且机制不同的改动。在U同parent上单项验证后才能声称可移植收益。
3. 主线程选择达到召回约束且去噪有效的组件，测组合后的真实效果。记录各单项差值及组合差值，检查互作：Δ_AB−Δ_A−Δ_B；未测项不填预期收益。
4. 固定配置在DEV1850确认，保全部类型/失败分母，不根据DEV反复调参；最终全量TEST验证与D实际消费质量在后续系统阶段完成。
