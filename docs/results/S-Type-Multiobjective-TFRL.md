# S节点TFRL：分层目标、多优势与采样方案

## 业务定义与证据

用户明确“空值槽位”是有槽位类型，但没有槽位值。它不同于整条query无槽位、不同于意图允许但语音没提到的类型，也不同于模型无法确定类型。系统没提取出值不证明样本本来无值。需区分：类型成立且无值、音频有值但系统未恢复、类型是否出现本身未决。

学习476的598条gold_entities全部是非空type/filler，缺空值状态的独立标注。Z必须标unknown，不默认空集合，不把unresolved_types当Z。当前类型实验继续，原分母/协议不变；后续在原训练域做来源化标注后，才评价新增二级目标。

数量指去重类型数。同句两个place_name仍为一个类型；若一个有值另一个无值，集合不能完整表示，需另有mention级评价，不能悄悄扩充当前任务。

## 形式化指标

对样本i：合法类型全集L_i；实际成立的类型集合T_i；预测集合T̂_i；空值类型集合Z_i⊆T_i；预测Ẑ_i⊆T̂_i。未决U_i单列。协议失败计主指标失败，不伪装空集合。

一级：
- 数量一致 C_i=1[|T̂_i|=|T_i|]。
- 类型集合一致 E_i=1[T̂_i=T_i]。
- 数量对类型错 M_i=C_i(1−E_i)。

E成立必然C成立，不简单把两者相加重复奖励。类型部分正确：TP=|T̂∩T|，FP=|T̂\T|，FN=|T\T̂|，F1=2TP/(2TP+FP+FN)。双方空且协议有效的样本F1约定1，失败0；总体micro按总TP/FP/FN计算。数量误差N=||T̂|−|T||，集合误差D=|T̂△T|，N≤D，类型替换可能N=0而D>0。

二级只在Z标注已知子集I_Z上评价：
- 空值数量一致 C_i^Z=1[|Ẑ_i|=|Z_i|]。
- 空值类型身份一致 E_i^Z=1[Ẑ_i=Z_i]。
- 联合完整正确 J_i=E_i·E_i^Z。

“无值类型不漏提”再分两层：
- 类型供给召回 R_Z^T=Σ|Z_i∩T̂_i| / Σ|Z_i|。
- 空值状态召回 R_Z^Z=Σ|Z_i∩Ẑ_i| / Σ|Z_i|。
- 空值精确率 P_Z=Σ|Z_i∩Ẑ_i| / Σ|Ẑ_i|，防止全报null。

分母0记不适用；Z未知不令E_Z=1。遗漏的空值类型计FN，不只在类型正确子集上评价空值。整条T为空的正确率/误提率另列，不冒充上述空值类型指标。

## 策略级目标与多优势

策略质量向量 V(π)=[Ē,C̄,F1_micro,R_type,P_type,Cover_nonempty,EmptyCorrect,−M̄,−ProtocolFail]。Z可用后附加[J̄,Ē_Z,C̄_Z,R_Z^T,R_Z^Z,P_Z]及I_Z规模。不同条件分母不混合。

选择采用约束优先、分层比较：协议、非空完整覆盖和空样本误提等保护通过后，先优化一级集合exact；一级差异不足以支持优劣时比较二级联合正确，最后比较效率。数量是诊断，不能代替身份正确。

保护例：Cover_nonempty(π)≥Cover_nonempty(base)−ε_cov；FP_empty(π)≤FP_empty(base)+ε_empty。ε须预先配置并依据重复性确定，不能事后追分。探索可保留Pareto候选分析，不因任一指标微跌就全部丢弃；生产晋级另用冻结验证规则。按同样本配对修复/回退及不确定性报告，同语句多录音按utterance group处理相关性。

对同query、同策略G条真实轨迹，第m维奖励：
A_{i,g,m}=(r_{i,g,m}−mean_g r_{i,g,m})/(std_g r_{i,g,m}+ε)。

可配置综合优势 A*_{i,g}=Σ_m w_m A_{i,g,m}，w_m≥0且Σw_m=1。它用于提案优先级，不决定晋级。E与C不同时正向重复奖励；E为主，F1/FP/FN提供部分正确信号，C/M用于诊断。Z未知则mask该维，不能填假标签。保留原始奖励差，避免G2把微小差异和重大差异都标准化成±1。未决、短输出、低耗时不抵消类型错误。

改进TFGRPO流程：Generator按类别提出最多三条单机制策略；Evaluator真实重放；Reflector看成功/失败成对证据和知识冲突；Curator维护来源清晰的策略记忆及Pareto候选。零优势同错样本仍交ACE式根因反思，不能丢弃。冻结模型参数，开发gold不写回KB或示例。

## 优化点与证据强度

1. 奖励错位已证：B旧平均奖励.394→.538，学习完整覆盖261→243；245奖励上升中199确认集合不变。移除未决项仍可能受空样本收益支配，需要分层约束。
2. 提问目标与已提供信息混淆：问“当前歌曲艺术家是谁”不等于给出了artist_name；泛天气话题不等于weather_descriptor。需角色正反对照，不是统一更保守。
3. 知识冲突和角色边界：动作/幅度、主题/嵌套人地、商户名/类别、date/time。修订查独立TRAIN支持，不从开发gold写规则；few-shot需对比和覆盖，约两条例子不证明足够。
4. 输出契约已有干预：B少未决但损召回；confirmed-only全545 TP531/FN98（父522/107），同时FP245（父201）、exact298（父310）。学习exact263（父276），不晋级。取消未决释放部分确认，也增加误提。
5. 上下文待验证：每请求pipeline平均3219字符，多为审计标识。程序侧保审计、wire只留语义必要字段的A后继准备中，尚无收益。
6. 音频能力尚未分解：同音频同知识不同seed输出差异证明决策变化，不证明声学已排除。保持Omni音频直入，不恢复ASR级联；按已有录音组取证，不把参考文本当Omni已听懂。
7. 空值类型是当前标注盲区：缺Z金标且现任务只输出类型，不能从未决或无预测值构造空值真值。先制定一致标注，再增设值状态评价。

现有入口足以开展下一轮有针对性的实验，但不足以保证解决全部错误。多指标和多采样不自动产生收益，仍须固定样本、清晰目标、可追溯干预和独立验证。
