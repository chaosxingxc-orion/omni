# 完整测试集召回错例分析

当前冻结145条相似问库、Q15+D5并集，在13078条测试录音中漏召401条（3.0662%）。这些错误发生在P之前，不能归因于P排序、thinking或输出协议。

## 已确认的错误结构

| 观察 | 录音数 | 独立句数 | 含义 |
|---|---:|---:|---|
| 同句至少另一条录音成功 | 305 | 221 | 不能仅以这句话的语义不充分解释失败 |
| 同句所有录音失败 | 96 | 42 | 仍需区分表示、覆盖、语义与来源限制 |
| 合计 | 401 | 263 | 完整分母保留，不新增排除 |

305条中187条还存在同一录制编号的不同声道成功配对。该观察支持结果对录音/声道敏感，但没有听音证据，不能确认音质、截断、说话内容差异或编码实现哪个导致了失败。漏召与成功平均音频时长分别2.826秒和2.822秒，不能用录音短统一解释。部分正确录音也可能通过宽候选偶然命中，成功配对不能单独证明语音完全正确。

## 145条库是否覆盖不足

取消会议类别在小库里只有1条代表，其含义偏清空未来日程。上述失败录音与该代表余弦0.129；合法训练候选中存在更接近取消某场会议的问句，余弦0.324。颜色调整类别只有2条代表，失败录音与当前最近正确代表余弦0.209，却更接近降低亮度的候选（0.303）。这说明有类标签不等于覆盖了该类动作、对象和表达方式。

全401条中394条在原8554训练候选中有合法同类问句，其余弦高于当前小库第15名边界。候选已按原query来源闭包排除自来源；其中392条的正确卡仍合法，另外2条仍受整卡来源排除约束，不能靠换相似问直接解决。此结果只支持小库覆盖缺口：不是完整8554库的Top15召回率，也不是加入这些问句必然修复394条。扩库会改变其他标签竞争与边界，不能按TEST错例定向加入后再称独立测试收益。

## 应当优先验证的方向

1. 在TRAIN/DEV构造固定同句多录音及同录制多声道对照，检查预处理、长度/mask和表示变化；先分清录音内容差异、模型表示不稳、工程实现缺陷。不同说法同意图与同句不同录音需要分别统计。
2. 在TRAIN/DEV检验类别内部动作/对象覆盖与多录音最差边界，避免只奖励少数开发样本命中。保留最小库思路，但以稳定覆盖而非固定条数作为约束；先证明真实TRAIN少量补入有收益和零/可控回退。
3. 对作品名、品牌名等依赖实体知识的请求，区分锁定知识是否具备必要关联与query是否可识别，不要求模型自行编造知识。
4. 单词、无对象请求标为待审，不以漏召自动判坏样本。来源排除的2条单列审计；不为改善TEST数字放宽来源规则。

本轮只读分析，没有改库、改K、删除TEST或发送教师请求。后续教师应接收TRAIN/DEV根因证据与聚合反馈，产出可执行策略，再在独立开发回归上验证。所有401条有机器可追溯证据；人工语义审查为代表案例，不冒称全量听音或完成全部根因确诊。
