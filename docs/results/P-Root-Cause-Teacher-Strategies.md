# P Top3根因策略：教师提案与执行决策

## 输入和完成情况

ACE与TFGROUP分别使用独立模板，动态输入保留8个消费失败、4个同run真实成功和3个供给机制，共15个代表；完整1080实测聚合及Top1、LCO反证一并提供。教师负责提出策略，不逐条生成答案；原知识卡、gold及测试隔离规则不变。

两次本机请求均HTTP200、正常stop并完成，未重发。ACE耗时537.653秒，输入24702、输出31429（含思考25207），总56131 tokens；TFGROUP耗时724.546秒，输入24727、输出32958（含思考25078），总57685。合计113816 tokens，货币费率未知。输出上限各131072，思考目标是提示约束，不是已验证的服务端硬上限。

## 策略执行决定

|策略|根因假设与干预|主审决定|
|---|---|---|
|ACE C1 / TFG T3|system实体实例示例干扰P筛选；只启用已有无实例示例视图，保留合法标签/实体类型|批准独立实验；两算法最终配置相同则共用一次测量，不重复跑|
|ACE C2|知识卡边界存在但未被使用；只调整通用指令，按主动作/对象和排除边界比较|批准独立实验，原system、音频、卡和顺序不变|
|TFG T2|候选语义家族竞争；显式避免没有操作证据的同家族填充|可作为不同措辞候选；冻结文本后测试，保持动态min(3,n)合同|
|TFG T1|描述在决策点不可见或距离编号过远；建议内联完整卡|暂缓，先审计真实消息渲染；如果卡已完整可见，只能研究邻接或重复呈现，不能宣称修复丢卡|
|ACE C3|cap5丢失部分正确类；计数支持参与选类|暂缓，只有规则族而无确定算子；先核七条错例的真实支持关系，不扫描参数|

C1与C2不先叠加。B等价fixture的真实stage/prepare/register/admit已通过、launcher plan可构建，但实际request比较及教师候选激活仍在进行；没有新NPU实验已启动的证据。fixture没有模型调用，也不是策略收益。

## 主审纠正与评价

教师将部分跨合同差异误当同配置随机性证据，以及将“共同失败60条”与“双方都有供给的5条修复”混淆，均已纠正。LCO的469条response_format变化来自动态候选数，不等于非法解码漂移。两臂优势均值为（修复−退化）/1080，不等于未归一化计数。

不使用教师任意给出的净增5条或某类退化3条作为自动晋级门槛。先报告全1080配对修退与根因，再做固定保留集确认。P额外报告[需要筛选的308条](P-Selection-Difficulty)，避免无需筛选样本掩盖错误。

不因现有接口不足永久搁置57条未召回及零支持缺口，不将其直接交S当作P完成。合法TRAIN标签可以用于学习奖励和来源隔离校准；禁止的是运行时gold门控和TEST调优。信息不足已确认例外仍为0。

当前三路CPU工作是候选配置激活、音频传输证据审计、召回错例支持关系分析。均围绕具体根因，暂未产生新增精度收益。
