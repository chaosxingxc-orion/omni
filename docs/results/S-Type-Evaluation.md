# S节点槽位类型评价方案

当前任务：给定原音频与一个候选意图，输出该语音实际表达的合法槽位类型集合，不评槽值和同类型出现次数。正式类型准确率只评价正确意图分支；另两个候选无可靠金标，单列协议与成本。固定545样本（476学习/69隔离），不修改标注或分母追分。

## 核心指标

1. 类型数量一致率：预测去重类型数等于参考去重类型数的样本比例。诊断漏提/多提，不能独立证明正确。同句两个地点仍为一种place_name，不能用entity mention数量作类型数。协议失败不算数量正确。
2. 类型集合完全正确率（主指标）：预测集合与参考集合相同，不漏、不多、不替换，忽略输出顺序。正确集合已经包含数量正确，不重复加奖励。
3. 类型Precision/Recall/F1（辅助学习信号）：分别揭示误提与漏提，micro看整体，macro和逐类型support/TP/FP/FN看类别失衡。
4. 非空样本完整类型覆盖率：金标非空时，其全部类型都被确认；允许有额外类型，因此必须与Precision、误提同时看，不能靠输出全部类型刷覆盖。
5. 空样本正确率和误提率：单列金标无槽位样本，不让多报空导致整体指标看似提升。非空集合完全正确率同步报告。

## 错误诊断与工程指标

按完全正确、仅漏提、仅多提、既漏又多、协议失败五类互斥统计；另标数量一致但类型替换错误，构建类型混淆表。类型数偏差（少/多/绝对误差）只用于诊断。知识来源冲突/标注歧义另有证据台账，不默认归模型错误，也不自动移除样本。

协议有效率和样本回答覆盖率分开。合法空集合是有效回答，不等于漏答；模型调用失败/JSON失败不是合法空。原始失败计完整分母，不静默丢弃。未决比例只作诊断，不进入类型质量奖励；未采集未决的实验该指标为不适用，不视为零。当前只学习类型集合，不等于已完成槽值或端到端SLU。

迭代按相同样本配对报告修复/回退、空/非空表现、逐类型变化；G2两次采样只提供有限可恢复性观察，不声称统计稳定。未来冻结策略后用隔离集/完整测试报告泛化。

## TFRL目标与奖励

主目标是提高集合完全正确率；用类型F1/漏提/误提给部分正确轨迹提供学习信号，数量一致不单独加分，以免类型替换被奖励。空/非空分层，协议失败单独惩罚，完整类型覆盖与原正确回退作为保护指标。未决、JSON更短、推理更快均不冒充语义准确率奖励；效率另报秒/样本和tokens。

保留原reward账本与当前采样策略不变；离线比较移除未决项的类型主奖励。现有B在learning476奖励均值.394->.538，但完整覆盖261->243；245条奖励上升中199条确认类型不变，证明原聚合目标存在偏移。替代reward仍是待验证设计，不能以奖励提高声称能力提升。
