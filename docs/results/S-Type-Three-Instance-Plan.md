## 目前最重要的根因证据

原父有效结果中的201个多提类型全部在当前意图允许范围内，未发现accepted输出越界。问题主要是意图内角色、存在性、共存判决；枚举合法不等于选择正确。

四状态诊断仅使用476学习样本，分别观测仅A、仅B、A+B、两者均无。烹饪意图21条中food_type/ingredient出现单类扩成双类3次、相反单类预测1次、共存缩成单类1次、两者均无却输出类型2次。calendar_set原父的time/timeofday没有直接互换；不能把改卡后产生的迁移误当原父根因。小组结果不是总体收益，也不能仅凭类型集合变化认定语义替换。

## 晋级原则

主线程按证据有效性、根因反证、组合冲突、真实组合回归四轮审查。整体类型exact、非空完整覆盖、无类型混淆、逐类回退和成本共同判断；不按金标逐样本挑赢家，不将修复集合并集冒充系统效果。只有真实组合收益成立后才锁新基线、重新分发三路。
