# S节点：语音、文本证据与工具协作方案

## 当前判断

已知意图锁定合法槽位类型；当前语音决定哪些类型出现、出现次数、实体值及关系。知识构建需统一业务角色、示例与提取规则。不能把合法类型都填满，也不宜先预测一个固定槽位数量再强迫后续凑数。

May可指月份、人名或作品，转写本身不能消除多义性。大小写不是可靠语音证据。应结合上下文、固定意图、合法知识库的别名/类型/关系消歧；知识库命中给候选，不直接判定。开放人名、地名不能强制限制在有限词典中。无足够证据的样本保留歧义，不能工具强填或从参考答案补信息。

## 配置化执行链

before_model_call：锁定当前意图卡与真实训练示例；调用ASR生成带来源的转写，按音频SHA、ASR模型与配置缓存，三个意图分支复用。原音频和转写同时供Omni，标明转写可能有误。生成允许的工具清单和业务约束，不供评估参考文本/金标。

model：识别当前语音/文本的实体证据、业务角色、槽位类型和工具参数。输出可验证的结构化中间结果，不要求长篇自由思考。槽位数量由实体列表推导；多次提及、跨槽关系、含糊候选显式表达。

after_model_call：只调用注册工具。数值/时间工具解析限定span和单位；封闭业务词典映射别名；关系工具处理相对量、起止方向等。模型输出pattern_id和参数，不执行任意生成正则或代码。保留raw value、canonical value、工具版本和证据来源。无法唯一解析时保留候选与原因，不伪装确定结果、不静默弃答。

## 知识与工具类型

|类型|主方法|限制|
|封闭业务关键词|业务字典、别名和上下文规则|有限集合须有合法来源；命中不是语义裁决|
|开放实体|音频/转写证据与语义抽取，可选知识检索|新名字不应因字典未收录被删|
|数字、数量、时间日期|模型定位语义角色，工具解析数值和组合|相对日期需真实参考时间，缺省不猜|
|关系与复合实体|模型识别关系，工具验证组合|不用关键词正则独自裁定全部业务逻辑|
