# S节点non-thinking对照

最新决策：语音没有大小写信号，大小写不作为模型理解能力或教师优化目标。格式差异由输出规范化与评测分层呈现，冻结strict原分保留，不回写历史成绩。

下一轮优先准备S non-thinking对照。复用固定545条、1635个独立意图分支，冻结P、音频、知识卡、动态few-shot选择、提示词、输出结构及并发64。首先只关闭thinking，输出上限4096、上下文65536保持；使用引擎真实支持的关闭方式，实际响应确认没有额外思考生成。当前是CPU准备任务，尚无OFF实验结果。

当前工程把ON写在输入校验、请求映射与预算模板中，需要显式配置新版本；旧ON基线保留。不能只改表面开关而让旧校验阻塞，或绕过源、音频与知识一致性检查。

主要比较冻结归一化槽位F1与全槽正确率、非空槽提取、空槽误提、有效输出率；同时报告原strict、官方条件SLU、耗时、tokens及请求时延。69条来源隔离集不进入教师反馈。边际收益须检查运行波动，之后再优化OFF提示词；不同时修改多个因素。

实验使用仍获授权的三个实例，已释放实例保持停用。关闭thinking适合信息提取是待验证假设，尚不宣称精度或速度改善。
