# 实验产物保留与深度清理

依据最新用户授权，已结束实验保留最终结果与可复现资产，删除可重建中间过程文件。旧的全量封存习惯不再作为整目录保留理由。

## 必要保留

- 数据集、原始基座模型、特征、必要知识库与索引。
- 可复现的基线代码、配置、环境及必要依赖。
- 最终逐样本预测、指标、数据版本、运行配置与成本记录；尽量整理成紧凑结果包。
- 当前运行和排队任务实际依赖的输入、代码、断点与互斥状态。
- 后续学习已经选用的必要轨迹，以及未解决请求的恢复证据；不将全部历史日志自动划为学习资产。

## 重点清理

已结束实验的重复源码工作区、可重建预备输入、重复语音请求载荷、传输包、展开副本、旧临时环境和过程日志。先保留小型最终结果及复现配置，再删除中间产物；不为清理复制完整巨型归档。

对被当前任务引用的中间文件，保留具体依赖闭包，不因此保留整个历史实验树。共享文件系统只清理一次；不停止推理服务，不扩大到未授权目录。
