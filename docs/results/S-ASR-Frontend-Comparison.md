# S节点ASR前端可行性与配对方案

Qwen3-ASR-1.7B适合作为独立语音前端候选，当前证据不足以直接替换Omni槽位节点。固定环境中已核到ASR注册、实现及Ascend专用部署资料，已有本地权重；尚无本任务的实际启动、精度和性能结果。

对照拟沿用固定545段音频和三意图分支，476条学习、69条按来源隔离验证。每段音频仅转写一次，按音频内容、模型版本及配置缓存，三个分支共享后进入同一冻结槽位抽取器。原音频实验保持封存；文本路径另立adapter与实验定义。

ASR提供转写，槽位角色和边界仍需抽取器判断。WER/CER与槽位精度分别报告，关注专名、数值、角色和跨度，并核算转写加三分支抽取的完整成本。参考转写仅作学习诊断。

只读核验和规格已完成，未调用模型、占用加速卡或部署候选。先完成既定Omni对照，再依据独立配对实测决定前端选择；当前不宣称精度或速度收益。

后续CPU工作已经启动：复用原固定镜像、数据与工具，实现配置化ASR缓存及文本槽位adapter，当前没有分配NPU或改变在线模型。参见[知识卡优化方案](S-Knowledge-Card-Optimization)。
