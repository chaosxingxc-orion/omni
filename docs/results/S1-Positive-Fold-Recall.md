# S1正确标签所属Fold诊断与95%召回目标

目标：固定正确类型全集，首先保证正确标签在其所属Fold内被标记。推理仍执行全部10Fold，不用gold选择Fold；正Fold仅用于离线诊断。

令Y_if为样本i在Fold f的参考类型，Z_if为输出：

R_type = Σ|Y_if∩Z_if| / Σ|Y_if|。
C_positive_fold = Σ[|Y_if|>0且Y_if⊆Z_if] / Σ[|Y_if|>0]。
E_false_empty = Σ[|Y_if|>0且Z_if=∅] / Σ[|Y_if|>0]。

当前B完整6681样本/66810Fold，6381正Fold，6444正类型机会，5666命中、778漏标。R_type=87.9268%，C_positive_fold=87.8232%；正Fold至少命中一个为87.9956%。完整样本覆盖83.3815%是不同指标，不可混用。

95%类型召回需要至少ceil(6444×.95)=6122命中，即净增加456；允许FN至多322。恢复旧错误但同时新增漏标会抵消收益。

Why：89.07%的漏标事件发生于全0Fold；B相对None新增170次漏标中158次落在全0Fold。当前主要可见失败是判空，不能把整体归成输出其他类型挤掉正确类型。只选参考外类型的74次中，16次所在Fold存在相对None新增的参考外类型；即使如此也只是竞争假说的候选证据，不证明模型内部竞争。全0也不能排除内部注意力干扰。

定义屏蔽解释范围有限：全0的693漏标中123属于定义同源屏蔽，570未屏蔽。未屏蔽不证明知识足够；不能从两组差值作因果结论。未听原声，不能认定声音不可辨或标注错误，更不能按失败删除样本。

How：先对全0簇做有来源的供给恢复和语音角色判别干预，并与现有U/E/K策略去重。竞争候选簇使用同样本/同知识的受控Fold呈现干预验证，保留正确反例，不用gold指导正式推理。新的裸0/1输出是独立协议实验，固定类型顺序、长度和映射，后处理不补位不吞失败；它可能降成本，不能预设能把召回推到95%。

逐类和逐事件证据保留在私有归档；脚本复用已归档配对结果、原知识来源，核对66810Fold、6444正类型、778FN和170新增漏标，无新模型调用。其他类型精度/参考外输出继续作为保护指标，不靠全选达95%。

## 空格分隔标记与独立判断

当前模型tokenizer实测：01010为5个数字token；0 1 0 1 0为9个token（4个空格）。不存在此tokenizer下0/10/10合并，但生成5个标记并不等于5次独立推理。遵照业务要求，新协议采用空格分隔的0/1，不输出JSON；固定顺序映射，缺位/多位/非01/截断不补0、不算有效空。

联合逐位输出仍有自回归依赖；独立逐类型请求每次只返回一位、请求间不传判决，是另一机制对照。当前55类型/10Fold，独立请求将由10次/样本变55次；总c64限流不乘55，不预设前缀缓存可消除全部开销。工程子进程正在实现联合二进制协议及兼容验证，并准备独立请求对照设计。尚无新协议模型效果或时延收益。

## 高召回证据与限制

供给增强臂在同批TRAIN的类型召回97.50%；其后继U仅增加语音角色提示，召回97.73%、正样本完整覆盖96.82%，但精确率18.73%→17.97%、参考外标签净增1480，未支持“减少多标”的原假说，尚未晋级。

B的778次漏标中，640次在supply与U均命中，10次仅supply命中、16次仅U命中、112次均未命中；另有B命中而supply漏33次、U漏24次。B与supply/U知识和协议不同，不能将此匹配观测当单变量因果，也不能把各臂命中并集当可执行系统的实测收益。下一步验证高供给与0/1判别的受控组合，保留全样本和正Fold指标。
