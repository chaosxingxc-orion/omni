# 意图内槽位四状态诊断

此CPU脚本只消费既有评分结果，不调用模型。输入545正确意图分支，严格选取476学习样本；69隔离样本不参与选类。运行：

```bash
python pair_diagnostics.py /path/to/type-scores.private.jsonl output.json
```

输出每个预先指定易混对的“仅A、仅B、A+B、均无”金标与预测交叉表，协议失败单列。附带JSON是原type-only基线的聚合结果，不含原始query、音频、轨迹或样本ID。类型对会重叠，不能将错误计数相加当总体样本数；相反单类预测只是线索，不能自动归因语义替换。组内分母较小，没有共存样本的组不能用来证明共存能力。
