## CPU 与 NPU 异步规则

CPU职责一负责准备知识卡、提示词、few-shot候选与合法TRAIN组采样，完成输入、来源和预算检查后才进入ready。CPU职责二负责执行调度，各路独立消费ready队列；CPU职责三负责评分与归一化评测。均采用独立CLI子进程与脚本。

每路储备至少一项ready和一项CPU准备任务；进一步按实测秒/分支核算剩余工作小时，任务数量不能代替12小时容量。后继包括教师根因策略、单机制提示/知识卡候选、真实分组rollout与冻结P下TRAIN轨迹采集。重复基线占位不算有效负载。

终态事件触发接续，常规观测间隔600秒。CPU评分、归档及教师等待不阻塞无科学依赖的NPU任务；确需前序结果的策略保留依赖，准备独立任务补位。执行脱离SSH、复用journal/checkpoint，未知响应不自动重发。队列不足或执行异常须记录，不能以服务存活代替负载证明。
