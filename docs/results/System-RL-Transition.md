# System RL：从TFRL封版到轨迹与LoRA训练

当前为设计交接，尚未启动LoRA训练。三阶段为系统设计搭建、参数冻结的TFRL系统优化、基于system RL的系统级进化。本轮探索截止2026-11-14 04:15 UTC；届时锁定实际有完整证据的基线，未完成候选不晋级。当前业务保留A，S2-v2冻结，DEV1850模型评估和TEST13078完整报告尚未完成。

## 学习目标

主模型统一Qwen3-Omni-30B-A3B-Instruct，thinking OFF。最终目标是提高意图与实体多重集全部正确的端到端joint；官方槽位F1、意图准确率、协议有效率、多模态能力与成本为约束。P覆盖率、S1类型P/R、S2值质量、D修复/损伤率用于定位问题，局部提高不能抵偿系统退化。

完整B+S候选已被拒绝：严格槽位F1从40.7263%降到40.0558%，95%配对差区间[-1.0078,-0.3291]个百分点；整帧1097→1112的差区间跨0。这说明知识和提示局部增强不能替代端到端验证。

## 轨迹构建

一个episode包含一个query的完整P、全部S1 Fold、真实S2分支和D执行。并行节点以依赖图记录，不按返回顺序伪造时序。必须保存每次调用的实际输入token、实际知识/示例、模型原始action token、行为logprob、节点与adapter版本、rails变换、最终输出、奖励和失败成本；上游输出在后继prompt中属于观测，不能再次计入action loss。

按最新约定，每轮冻结系统并重新构建训练数据：仅初始检索候选非空的TRAIN样本进入学习范围，不要求gold已被召回或P@3正确。按80%真实错误轨迹及其离线正确标签、20%系统实际正确轨迹构建纠错数据；最初无召回样本不训练，仍报告排除量和覆盖率。历史TRAIN6681和DEV1850的P@3筛选更严格，不能直接冒充新准入人口。错误动作与预期标签分开保存，不伪造未执行的正确轨迹。缺行为概率的历史greedy记录只能用于分析或合格SFT，不能补概率伪装on-policy RL。

GRPO先按当前冻结策略的错/对来源80/20选query，再采G=4完整随机轨迹，组内冻结工程与策略版本。完整组不能按结果裁剪凑80/20；纠错监督数据的比例与RL新组实际错对比例分开报告。恒奖励组如实保留，不无限补采成功结果。业务greedy评估与随机训练采样分开配置。参考文本与gold仅离线使用，不注入audio-only业务输入。

正式轮次先按5000条纠错记录（4000错/1000对）、至少1000条验证人口规划，并单报独立source和重复曝光。125个query draw×G4仅是成本/信号探针，不承担效果结论。筛选轨迹不混入新的G4组；组内使用同一录音，轮内每次策略更新后采新行为组。纠错CE只学习实际输入下可实现、有可靠来源的目标，不正向模仿错误动作；终局成功也不自动证明全部中间节点正确。

同文本重建不能替代原始token轨迹；首版每次调用独立训练，保留真实DAG。优势按完整episode归组，不按Fold或动态分支重复计算奖励。相同prompt的独立随机采样全部保留，不能仅按prompt哈希去重。

## 算法和适配器

建议复用既有verl环境，先做终局奖励的GRPO；同预算保留RLOO-clipped对照。GRPO组内标准化改变样本权重，不能称为原joint期望的无偏梯度。PPO+critic仅在实际信用方差或稀疏奖励问题出现后研究。Agent Lightning/rLLM用于多调用轨迹接线参考，Search-R1用于观测token loss masking参考，不等于当前Omni+NPU训练已验收。

先比较四节点各rank16和共享rank64 attention LoRA，冻结基座、音频塔、视觉塔、投影与对齐参数。近似总参数相同不意味着单节点容量相同；同时记录梯度冲突、路由、吞吐及端到端效果。初版不扩展MoE experts/router。适配器关闭回归与多模态回归必须保留，冻结塔不保证能力不会下降。

实验顺序：真实Omni训推概率/梯度/保存恢复验收 → 只采样测成本与奖励分布 → 比较LoRA组织 → 单独比较优势算法 → 单独比较真实/合成配比。只扩展已获证据的方向，不做全排列。

## 合成数据审计

clean合成数据有69102个录音引用。按原始完整DEV/TEST的ID或规范化文本排除后剩57709；进一步排除与真实TRAIN同来源或同文本后，剩31501录音引用、6481元数据行、6377唯一文本。它们仍是候选：未完成音频可用性、近重复、语音来源和全历史使用审计。指定三份历史名单没有合成音频，不证明全项目从未使用。

按来源组隔离后再采录音，优先真实/合成100/0与75/25；只有明确收益后再考虑50/50。比例按来源曝光定义，同时报告录音数、独立文本、音频时长、token和卡时。80/20错对比例与真实/合成比例是独立轴，每轮交叉统计。按用户约定，每轮训练后做固定测试评测，有可靠端到端收益才晋级并由新系统重采下一轮；测试错例不回流训练/知识/教师策略。完整TEST13078与clean12991并列，评测不因训练准入过滤而换分母。反复依据同一测试集晋级存在适应性选择偏差，最终泛化确认需要独立留出集；没有时如实标明迭代测试结果。历史测试使用也必须披露。

## 镜像复用边界

既有训练镜像和Omni LoRA环境实际存在，但ASR训练成功不证明Omni系统RL可直接运行。历史Omni存在FSDP包装与批处理logprob偏差，须先验收真实权重、音频mask/位置、行为概率、更新、adapter导出/路由与恢复。使用固定镜像与外部配置/源码，不另建反复安装流程。热状态保持本地持久化，共享数据模型只读。
