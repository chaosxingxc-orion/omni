# 开放域事实问答、闲聊与业务others的区分

原始TRAIN标注核验：8条至少一条正确路线cosine<0.01的样本全部为qa_factoid，包含人物参演时长、人物身高、最长河流、国家地理意义、美国首任总统。不是general_quirky或audio_volume_other；不能为了简化路由更改原标签。只有1条所有正确供给路径<0.01，其余有较强相似问路线。

## 三种不同语义

|类型|当前标签示例|应判断的信息|
|---|---|---|
|开放域事实问答|qa_factoid|请求确定事实，人物/地点/事物/事件主题可很分散|
|开放对话|general_quirky|聊天、意见、感想等，仍需按原业务边界核验|
|域内剩余类别|audio_volume_other|先确认音量业务，再判断请求未落入明确升/降/静音等动作|

当前60类库中只有audio_volume_other名称含other，并无一个可直接把所有低分样本装进去的全局others标签。上述自然语言边界来自当前锁定的TRAIN派生知识卡，是解释材料，不冒称已查到官方穷尽定义；原始样本gold已独立核。

## 系统性问题

向量相似问通常同时反映话题、实体和请求形式。某演员参演时长与城市海拔的主题不同，仍可同属事实问答。以具体话题近邻作为类别供给的必要条件，对qa_factoid这类广泛主题类别可能低效；“类别内必须所有问题语义高内聚”的要求也不适用于其原始定义。域内others还具有排除其他子类后的逻辑边界，并非一个天然的单一向量中心。

这支持把匹配当作证据而非唯一准入门：模型基于锁定业务定义判断请求类型、比较相邻意图，可在低置信路由后由D恢复。但不能用“所有近邻低分”直接推出others/闲聊，因为低分也可能来自语音表征、缺少知识代表或数据错误。原语义明确样本仍属于系统需处理的有效任务，不能按主题开放而清理掉。

## 数据集验证建议

仍按用户要求先数据验证，不改工程。质量审核独立排除确认错误；阈值选择报告qa_factoid、general_quirky、域内others及其他具体动作类的分层路由率/正确标签覆盖，不只给总体分数。可比较现有近邻供给与“低置信时提供少量锁定的请求类型边界卡，由D判断”的概念方案，但须先冻结路由与边界卡，不用gold直接决定运行路由，不将qa_factoid标签对所有样本强塞而称其为分类准确提升。

D需判定意图与原定义槽位，不需要正确回答演员参演时长等外部事实才能完成SLU任务。因此这个方向不要求新建开放域事实知识库，也不允许模型生成意图知识。后续D实验必须包含根因驱动提示词优化和独立验证，不能一次直接调用就得出方案无效。

## 用户锁定：两类退出检索，改为P常设知识卡

`general_quirky`与`qa_factoid`从动态相似问和描述检索池同时移除，但保留原任务标签与锁定知识定义，作为P常设卡由模型判断。相似问145→121（移除16+8），描述60→58，均在移除后重新取TopK并补位。静态卡单独供给、去重，不计成召回算法发现的标签。

先数据集消融及小规模P验证，不修改生产工程。错误样本审核继续，确认错误排除后形成有效统计；不因主题开放或低分删除有效样本。两张常设卡仍需来源合法；来源冲突时使用已验证合法版本，不能关闭来源门控。报告分别展示其他58类动态召回、两类P真实识别、其他任务误判到两常设类的回退，不能以供给覆盖恒真宣称模型提升。

低置信路由依据应在追加常设卡前计算，否则P输入永远至少两张卡会掩盖“无可信动态候选”。已有事实问答补库/替换探索仅保留诊断，尚未运行的这两类补库任务停止；不继续通过不断增加主题例句覆盖开放域。实际P实验仍在输入准备阶段，尚无模型结果。
