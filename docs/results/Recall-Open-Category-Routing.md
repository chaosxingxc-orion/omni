# 开放域类别常设卡与 P 节点验证

当前结论：将 `general_quirky`、`qa_factoid` 从动态检索池移出并固定供给，可以改善候选覆盖；P 是否正确使用它们，仍取决于证据和呈现方式。最新小规模实验中，常设卡块前置得到正收益，尚未证明完整开发集或测试集收益，未晋升生产。

## 已锁定的方案

两类保留原标签和锁定知识卡，退出动态相似问与描述候选池。相似问145→121，描述60→58；先移除再分别取Q15、D5并合并标签，最后加入两张来源合法的常设卡。P输出三个候选索引，由程序映射标签。动态为空不强制跳过P，因为常设类别仍需由P判断。

当前实验中，其他动态类别各带一条query相关的合法TRAIN例句；两常设类别不带动态例句。后者是当前实验配方，不是用户禁止一切辅助例证。类别固定准入与类内辅助例证检索是两个独立设计决策。本轮未加入辅助检索、D恢复或新阈值。
