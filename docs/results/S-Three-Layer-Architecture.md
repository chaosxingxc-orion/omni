# S节点：知识与ASR、Instruct、Tools

S采用统一的三层结构：**知识与ASR → Instruct → Tools → D**。保持Instruct作为P/S模型基线，复用现有before_model_call与after_model_call。

|层次|职责|优化方向|
|---|---|---|
|知识与ASR供给|知识给业务定义、实体和示例；ASR给当前音频的文字证据，原音频保留|知识一致性、按意图投影、示例选择、转写与热词质量|
|Instruct语义处理|判断语义角色、定位证据、提取完整槽位、保留歧义|类别级任务指令、上下文组织与TFRL策略|
|Tools确定性处理|数字/时间/单位解析、合法字典映射、验证及组装|工具正确性、配置覆盖与接口实现|

ASR不是事实库，转写可能有误。模型结合原音频和文本判定，工具依赖明确的证据与语义定位；不凭空补值，不用正则代替语义消歧。相对日期缺参考日期或时区时保留未决。

轨迹分别记录知识/转写来源、模型判断、工具输入输出与状态，保留原值和规范值。错误按供给层、模型层和工具层归类；知识事实放外部记忆，通用策略通过TFRL跨样本验证，工具通过确定性实现修复。

S输出每个候选意图的槽位、证据、有效性和未决项；D负责最终意图和跨候选裁决。合法空槽、解析失败、证据不足不能混淆。不以S全部错例清零作为D开始的前提。

当前知识与Instruct基线已实测；ASR辅助S实验正在执行；工具rails已通过CPU检查，完整三层系统的真实收益尚未验证。先复用当前实验和接口，不因架构命名重写基座，不运行三层配置的笛卡尔组合。
