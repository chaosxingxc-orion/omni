# S1功能基线与TFRL优化入口

## 当前决策

先修复并锁定S1功能基线，再开展TFRL。S1独立于意图：输入原始语音，在分Fold候选中判断槽位类型；不填槽值。S2负责候选值，D负责最终消歧和组装。正在运行的instruction-only对照作为诊断，保持其输入不变，不把人工提示词候选称为已完成TFRL。

## 三个配置化入口

| 入口 | 构建与消费要求 | 优化方向 |
|---|---|---|
| 知识卡 | 从锁定知识源构建定义、支持证据和边界，保留来源与版本；避免同源排除后仅剩类型名 | 定义完整性、语义边界、冲突消除 |
| Fold间判决描述 | 当前Fold只加载与其类型相关的跨Fold区分规则；相关类型用于参照，输出仍限当前Fold | 易混类型区别、允许共存的条件、证据不足保留候选 |
| 相似问示例 | 用运行可得音频query表征检索TRAIN完整句示例，再投影其已标注类型；排同源和禁用来源、去重、限制预算 | 相关性、类型覆盖、示例多样性与判别信息 |

Fold保持并行，不依赖其他Fold的输出才能运行。相似问不依赖P预测意图，不用目标query的参考转写或gold，不把整句query向量与孤立槽位值直接算相似度。检索只是供给例证，不硬裁候选类型；示例未标某类型不自动等于该类型不存在。缓存缺失须记录降级，不能冒充动态检索完成。

## 每Fold的显式空选

增加可配置控制标签 `NONE_OF_FOLD`，含义为“目标语音不支持本Fold任何业务类型”。它不进入55类业务本体、相似问标签、S2或D，也不表示语音无效或整条样本没有槽位。

- 模型应在None与一个或多个有证据类型之间选择；None不能与真实类型同时输出。
- None-only由after rail转为有效空集合；历史空数组保持兼容并单列计数。
- None与真实类型混合时，保留合法类型、去掉None，记录协议冲突；不能用None覆盖已输出的证据。
- 截断、请求失败和无法解析保持失败状态，不能冒充None或正确空输出。
- 沿用已接受的array+enum结构；互斥由指令和rails检查，不新增未经服务验证的schema关键字。

## 证据与验证

旧基线6681条、66810 Fold中，60429 Fold按金标为空，31567次仍输出类型（52.24%）。这是空Fold误选严重的证据，不证明缺None是全部根因；原协议已经允许空数组。

None先在相同数据、知识、模型及Fold上做配对验证。报告空Fold误报率、正Fold覆盖、样本完整覆盖、类型集合准确率、micro precision/recall/F1、额外候选数和控制标签冲突。保留失败样本全分母，不以输出减少或整体二分类accuracy替代业务收益。

## 功能验收与TFRL顺序

先锁定三个入口及None的before/after接口、来源排除和并行调用测试，再通过真实推理验证运行契约。复用6681探索集及既有1850开发集，不重新抽样。基座验收后，教师只接收错误机制摘要和代表训练轨迹，对三个入口提出可追溯策略；知识候选须编译、校验并锁定后才能供给运行模型。

TFRL以覆盖率和准确率的联合收益选择策略，保留修复与退化案例，先比较知识供给和消费机制，不做无依据的排列组合。模型参数冻结，S1规则不得反向恢复意图硬约束。当前仍处于功能实现阶段，未宣称新入口或显式None已有精度收益。


## 全量提示词诊断结果

同一6681条TRAIN学习样本、同知识/模型/Fold，仅把system指令明确为判断目标语音证据。结果如下；不是None实验，也不是开发集泛化结果。

| 指标 | 原基线 | 目标语音证据指令 |
|---|---:|---:|
| 类型precision | 14.18% | 23.42% |
| 类型recall | 94.12% | 89.46% |
| 类型F1 | 24.65% | 37.12% |
| 正样本全部类型覆盖 | 91.89% | 85.63% |
| 类型集合完全正确 | 3.08% | 10.46% |
| 每样本额外候选 | 5.49 | 2.82 |

完整覆盖修复29条、退化311条。按source_group进行2000次配对bootstrap，覆盖差为−6.27个百分点，95%区间[−7.08, −5.49]；recall差为−4.66个百分点，区间[−5.24, −4.07]。不能以precision/F1改善单独判胜，当前不锁定此指令为更优业务基线。

退化集中于date净少111个正确类型命中、person少41、event_name少34、place_name少28、time少23。代表样本包括相对日期与事件短语被整体漏掉，且对应知识定义仍在；因此不能把所有漏标归于定义缺失。未逐条听审，声学原因和具体指令机制仍待验证。None保持独立干预，知识优化优先补足判别证据，避免继续笼统提高选择门槛。

## 知识构建功能交付

公共构建器已提供来源锁定的54类独立通用释义备选，仅在原定义因同源隔离被屏蔽时使用；原依赖不删除。137条旧规则完成任务适配审查，42条适合独立多候选S1，其中31条通过全局来源排除，其余不供给。意图条件、槽值格式和最终单标签决策规则不搬入S1。

固定镜像测试32项执行通过、2项原生环境测试跳过，新增12项全部执行。真实6681条CPU知识视图审计通过：367455张卡视图中556处定义文本改变，7815个来源引用核验，60129/66810个Fold可供给规则。相似问供给准备了7719条来源受约束TRAIN整句；动态检索缓存仍在接入。这些数字证明供给实现，不代表新增模型精度收益。
