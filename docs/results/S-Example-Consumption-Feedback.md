真正变化的4个正确意图分支，输出完全相同。关键错例中，语音参考内容为salmon，父子均提取pasta；去掉一条重复示例未解决错误。原本正确的tomato soup等输出保持不变。

两条全槽修复均来自130个输入不变分支：一条增加了event_name，另一条将briskets改为brisket。输入不变分支共33个输出变化，说明同配置重复执行仍有输出波动。不能将这两条修复或总体F1微增归因于去重，也不能仅凭本次耗时下降宣称稳定效率增益。

4个空签名竞争分支只有一条从无效变为有效，其正确意图评分分母为0，不报告100%精度。
