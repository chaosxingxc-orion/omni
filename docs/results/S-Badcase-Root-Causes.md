# S节点错例根因与调整建议

更新：2026-11-10。固定545条，P冻结、Top3独立进入S，离线只评价正确意图分支；不是端到端或测试集指标。本次复核不新增推理。

## 结果与边界

历史单意图＋动态few-shot基线：219条归一化全槽正确，323条输出合法但不全对，3条正确意图分支无效。非空标注391条中126条全对；空标注154条中93条全对。详细策略诊断只使用来源隔离后的476条，69条隔离集不反馈教师。

323条合法错例的重叠症状：238条漏值或值不同、299条多值或值不同、168条多出标注之外的槽类型、81条跨度差异、27条数值表记候选。症状不能相加，也不能等同于已确认根因。

## 细分类主审结果

已完成476条学习样本中285条错例的逐mention分类，见[细分类结果](S-Badcase-Fine-Taxonomy)。第一轴为具体错误表现，知识构建与消费列为第二轴。模型JSON违例与程序bug已分开，表记差异也拆成冻结typed已接受与尚不接受两组；未听音不确认声学原因。原评分不变，不据候选归因删除样本。

## 三条无效输出的原始响应复核

两条以4096 completion tokens达到length：JSON未闭合且尾部持续空白。一条仅510 tokens正常stop：JSON可解析但输出空字符串实体。它们不支持“统一增加预算即可解决”。当前没有证据证明这三条是解析器把合法结果误拒。

建议局部明确空实体数组契约，在引擎支持范围内验证结构约束及收尾。保留原失败及恢复输出的区别。已有compact实验虽然把全部分支invalid15→1，却使typed全对219→217、strict163→155，不应整体替换。

## 归因可信度与下一步

403条父/候选输入完全相同，其中146条预测或合法性不同。一次修复不能都归因于策略；必要时做小范围匹配父对照，分别统计目标TP/FP/FN、非目标回退与成本。

尚未人工听音，不把模型答错直接判成数据缺陷。明确标注错误或样本自身信息不足需核验原音频、标注与同类证据，保留排除记录和原分母。

优先完成已有卡片冲突修订与角色证据实验；随后验证来源支持的判别示例选择。协议修复限于真实失败，数值工具限于证实适用的错误。独立验证集用于评估，不反馈教师。局部新实验的本机评分草稿不作为已锁定收益。
