## 任务依赖

- 固定roster/缓存准备 → 三路单卡编码 → 自动CPU评分/归档 → 多录音根因反馈。
- 来源内容审计 → 来源安全内容构建对照 → 全量逐例来源与指标验证。
- 少量明确语义候选 → 有界增补搜索 → 原DEV/FoldA与TRAIN逐例回退检查。
- 已完成TRAIN诊断 → 教师多策略提案；本地实际实验反馈 → 下一轮教师策略修订。

三路编码只申请空闲0–2卡，既有TP4服务保留。当前尚未证明NPU满载，不能把服务驻留或CPU任务当有效推理。新编码总量、缓存命中、秒/条、实际卡时与ETA在CPU准备终态和编码开始后原位补充，不以2646全部视为新前向。
