## Why / What / How与对抗审查

| 错因方向 | What：观察 | Why：待验证机制与反证 | How：干预与验收 |
|---|---|---|---|
| 知识供给缺口 | 部分关系、事件请求仅有名称或有限示例 | 定义覆盖可能不足；name-only也有命中反例 | 用锁定来源补定义/边界，检查真实输入可见性与类型退化 |
| 已供给但未判别 | 明确时间、流派等定义及示例仍漏 | 不足以归结为缺知识；近邻有保有丢 | 固定知识，改变语音角色判别方法，保护隐含和未知值角色 |
| 示例/话题投射 | 目标语音未明显表达的关联类型被新增 | 参考内容可能被当目标内容；也存在参考标注粒度张力 | 消费策略单变量验证，按示例真正变化与未变化请求分层 |
| 判决协议偏好 | Others新增大量参考外类型，也恢复部分正确类型 | 多个提示因素混杂，schema并未强制非空 | I/L分别隔离判断句与选择数量要求，不直接弃用Other |
| 成本与表示 | 布尔输出约3.77倍、卡时约2.57倍 | 输出表示有固定负担，但引擎和时段混杂未排除 | 固定顺序bool数组为待审成本候选；先验证映射和语义非劣，不宣称已加速 |

## 数学目标与学习反馈

令第i个样本金标类型集为Y_i，预测为Z_i，完整执行指示为c_i：

- 正样本完整覆盖 C = Σ[c_i=1且Y_i⊆Z_i且|Y_i|>0] / Σ[|Y_i|>0]。
- 类型召回 R = Σ|Y_i∩Z_i| / Σ|Y_i|；类型精度 P = Σ|Y_i∩Z_i| / Σ|Z_i|。
- 平均额外类型 E = Σ|Z_i−Y_i| / N；另报空参考正确率、集合exact、每类型PRF和全部失败成本。
- 配对修退满足 ΔTP = 恢复正确−丢失正确，ΔFP = 新增参考外−移除参考外。
- 优化变量 ω=(K,R_policy,p,q)：知识构建、消费策略、提示词、输出协议；模型参数θ冻结。报告实际影响率ρ=改变请求数/全部请求数。

借鉴ACE维护来源可追溯的观察—反思—记忆修订；同一科学parent内进行组相对参数冻结策略搜索。向量v=(C,R,P,−E,空正确率,exact,−卡时)用于多目标反馈，相对优势 A_jd=(v_jd−mean_d)/(std_d+ε)。只有两臂时优势接近±1，不代表效应大小或显著性；必须同时看原始差值、source_group配对区间、修退类别和成本。不同parent不能混排。

U/E/K原预注册门槛：完整请求无未知；覆盖和recall差值95%区间下界≥−0.5个百分点，precision不降且extra不增；再要求extra相对下降≥5%且差值区间上界≤0，或exact提高≥1个百分点且差值区间下界≥0。逐类退化另审，并在固定DEV确认。这是研究门槛，不能事后套给B或I/L，也不是业务保证。
