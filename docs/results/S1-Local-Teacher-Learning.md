# S1子进程教师与错因驱动TFRL

## 当前执行方式

教师改为Codex CLI子进程，不再接入远程教师API。主线程负责多轮对抗审查、实验决策及结果整合；CPU分析、策略编译与NPU实验异步。现有供给和Other槽位对照继续运行，不因教师切换重跑。模型参数冻结，学习产物为版本化知识、消费策略及提示协议；尚未产生此流程的TFRL收益。

## 全量错误与证据

冻结6681条TRAIN探索样本、1850条DEV。首轮合并原始、grounding与None三臂的全部错误索引，包含持续错误、退化和修复，后续接入供给与Others终态。历史353条变化案例不能代替全部错例。分别统计样本集合错误、漏类型、参考未匹配类型、协议错误；多原因允许重叠，未确定原因明确保留。

每类根因采用以下格式，并保留私有逐案证据和来源SHA：

- **What**：现象、错误类型、数量与分母、真实请求供给及输出。
- **Why**：支持证据、反例、替代解释，标明观察事实、机制假设或干预支持。参考未匹配不自动等于语义错误，未听审不判断声学缺陷。
- **How**：改动部件、候选配置、预期修复、潜在退化，以及能推翻假说的实验结果。

脚本覆盖全量错误索引，语义审读按机制簇和异常案例展开；单独报告实际审读覆盖率，不能把规则归类称为逐条因果确认。

## 策略与对抗审查

每轮提出4–6组具有不同机制的策略，按知识构建、知识消费、判决协议区分，不能只是同一指令换词。优先实现其中证据最充分且改动独立的候选，其余并行准备。所有策略保持S1独立于意图、仅选类型；其他槽位候选经after过滤，不扩展55类业务本体。

主审检查结果倒推、输入证据不一致、预测减少掩盖漏标、训练样本背诵、被忽略的反例和对比条件变化。被否决候选带理由退回原职责子进程；需要新编译操作则实现最小支持，不能将探索永久限制为已有操作。知识重述必须由锁定来源支持，不能凭空生成业务知识。

## 实验与学习反馈

借鉴ACE的观察—反思—记忆修订循环，以及组相对多策略搜索。每组包含同一科学parent，复用数据、推理配置和评分器；相对优势用于诊断，不冒称参数GRPO。不同机制有明确证据时才组合，避免盲目排列组合。

令金标类型集为Y、预测为Z：正样本完整覆盖C=mean(完整且Y⊆Z)；R=Σ|Y∩Z|/Σ|Y|；P=Σ|Y∩Z|/Σ|Z|；额外候选B=Σ|Z−Y|/N。另报空样本正确率、集合exact、每类型PRF、修复与退化、失败和成本。完整分母保留失败，不以全空或全选取巧。

组内按v=(C,R,P,−B,空正确率,exact,−成本)计算各维相对优势；零方差标无信息，未知值不填零。先检查覆盖与召回保护，再比较其他收益；最终选择界限在候选实验前冻结，不能用事后加权掩盖覆盖损失。TRAIN迭代、DEV验证，TEST不调优。

每轮交付错误索引、根因报告、策略差异矩阵、可执行配置、配对实验结果、主审意见及下一轮修订。子进程交互tokens与学生推理tokens分开记录，未知费用留空；不伪造远程API usage。


## 已授权的逐类型标记对照

逐槽位类型布尔标记作为与None、Other并列的正式策略。每Fold仍一次请求，返回本Fold各类型是否出现，after只汇总true类型；不增加意图依赖、不填槽值。缺键、非法值和截断保持协议失败，不能静默折算为false。类型存在但槽值未知仍应标true。

实验与Others共用None-only科学parent、6681样本、原知识和推理配置。None已完成的结果复用，Others继续执行，布尔标记在独立版本准备好后接续可用实例；不挤占同一实例并发跑两个队列。原输出预算256先保持，若不足必须显式报告并控制预算差异。比较完整覆盖、PRF、额外候选、误空、失败率、输出tokens及耗时，不能仅用预测更少判胜。

What：列表选择/显式空选可能影响多标签覆盖；Why：已有对照显示判空路径变化，但尚未证明布尔表达会改善；How：在知识及模型不变时改变回答协议，逐样本评估修复与退化。该策略已获用户授权准备，尚未取得模型结果。


## 语音理解优先

多标分析不能只围绕标签区别和知识组织。知识定义类型，模型必须依据当前语音表达的对象、关系与语义角色决定是否标注。供给增强后的覆盖提升并不证明语音理解提升；当前还不能量化理解问题和知识问题各占多少。

根因拆分为语音内容辨认、上下文语义角色理解、角色到类型映射、参考示例内容投射、标注缺陷。未听审或缺少可区分证据时保持未决，不能仅凭参考文本和最终标签定位内部过程。

下一轮优先包含固定知识的语义理解策略，与知识供给策略分别比较。它需要说明与历史“只选有证据”指令的实质差异，保护隐含角色与类型存在但值未知的样本；不能靠更严格的全局选择门槛压低预测数。逐类型标记继续作为协议对照，其收益需实验验证，不能预设为理解能力提升。
