# S基座按类别交付与TFRL能力优化

## 固定边界

用户锁定Instruct P/S；S按单个P候选及其合法槽位域提取，最终意图和跨候选消歧交D。原545数据与476学习/69隔离保持，P结果不重新混换。ASR辅助Instruct545当前正在接续，不暂停，不为新方法重复原模型实验。

## 三个分层

- 外部记忆：业务定义、实体别名、合法值、槽位角色、可选性、示例归属与冲突解决。知识来自锁定合法训练/业务来源，版本化并经before_model_call关联去重；模型/教师不能新增无依据标签和业务事实。来源不一致须记歧义，不能机械“卡覆盖示例”或反过来。
- 能力策略：在信息充分时，区分容器与对象、渠道与内容、时间与事件；只使用本音频/可信转写证据；完成所有有证据槽位并避免空槽过提。TFRL调整通用指令、示例选择策略和上下文组织，不把当前query->gold写入经验记忆。冻结参数，不声称已改变模型内在权重能力。
- 工具与交接：before选择知识与可选真实ASR；after解析、保真归一/工具投影、重复信息去除且保不同提及，给D结构化候选证据、有效性、错误与未决项。工具从已有rails复用。数值不强迫全样本转写，不凭空补值。

## 方法与验收

复用ACE经验累积和training-free GRPO组内相对反馈；每种算法独立固定模板+动态学习轨迹注入。教师只给根因、少量类别级可执行策略与适用条件/反证，不逐条代答，不混69隔离或测试反馈。先复用已完成轨迹，当前Instruct没有同策略多rollout时，不伪造GRPO优势，也不把两个模型当一个GRPO组。

候选以类别覆盖收益、完整实体召回/精确率、空槽误提、协议有效率、成本联合评价；一类修复需要在相关全部学习样本和原正确保护样本上验证，最终仍报原完整545。不用有限样本exact净增掩盖真实实体下降。通过同一旧父对照、冻结配置与轨迹来源锁定结果。

## S阶段完成条件

交付一份配置化可复现Instruct S基座；已知知识冲突有明确来源及处置；真实模型结果与全类指标可复现；可采集的学习轨迹；S->D接口贯通。输出合法空、协议失败、证据不确定均可追踪，不为追求100%格式虚构答案。不以所有错误清零作为进入D前置。D输入编译与离线契约验证现在并行准备，正式D效果实验依赖选定S产物即可。
