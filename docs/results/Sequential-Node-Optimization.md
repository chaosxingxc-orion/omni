# 按节点逐阶段优化与冻结

更新：2026-11-07，北京时间22:00。此页按用户最新明确输入替代此前“继续整链候选并行”的下一阶段计划。

## 正确的执行顺序

P独立优化多轮并验证收益 → 锁定P，只优化S → 锁定P和S，只优化D → 锁定三个节点后，再做handoff及系统级调整。不是P/S/D同时优化，也不是跑完整链后才分摊各节点责任。

工作基线保留P OFF、S ON、D ON。当前只进入P阶段，运行中的历史实验保存结果；不追加新的整链TFRL探索，不将历史PON探索自动晋升为当前默认。

## 第一阶段：只优化P

原始语音、锁定来源知识和P接口是输入；P输出合法候选意图及契约允许的信息。P-only采样不调用S/D，不生成假系统最终答案。历史轨迹用于建立输入、评价和教师反馈，修改P策略后必须实际重新采样P，不能回放旧P响应冒充新收益。

独立比较的指标：完整名单的合法输出覆盖、gold意图进入候选集的召回、按原始意图类别的召回/混淆、候选数、重复/缺失/长度失败、每条P请求的tokens与时延。原演员模板已核到按支持程度排序的要求；当前报告仍只计算集合召回，没有校准置信度或top1测量，不能将集合召回称为top1准确率。不能让增加候选数到上限成为虚假的唯一收益，也不能使用D的终态意图准确率作为P的独立奖励。

每轮先以同一父P配置、同一输入和同一名单比较多个候选。所有可用实例可并行运行不同算法或候选，但一个比较组使用相同服务配置；175与181的硬件/解码差异分别记录，必要时交叉配置控制，不能把跨机器差异归因于策略。NPU任务在CPU准备完成后进入持续队列；CPU评分、根因分析和教师调用并行。

## TFRL围绕P的两类可优化对象

- 知识构建：对锁定意图知识卡的解释、语义边界、组织和重复内容进行来源支持的改写；保留合法标签、原始含义和来源，不生成新知识或样本答案。
- 知识消费：P的召回、排序、去重、证据布局、上下文及提示词。单个试验只改一个声明的轴/组件，其余固定，先确定哪些改动独立有效。

GEPA、Reflexion、ACE、TF-GRPO都以P为当前目标，不按算法名称分配不同节点。每方法独立模板：输入实际P上下文、召回知识、原始输出、评价、代表错误和反例，要求多组可执行的P策略，明确作用位置、预期收益和回退风险。只输出P可编辑内容，禁止修改S/D。

GEPA候选用于P提示词搜索；Reflexion用于P错误反馈形成条件策略；ACE相关尝试用于锁定P知识卡的有来源解释/组织，缺完整机制时明确标记inspired；TF-GRPO只有同一P策略、同一输入的多条真实P轨迹和组内奖励齐备才执行，不能将不同策略的旧轨迹拼成一组。它们当前都是实施路线，不宣称已完成或已有收益。

## P什么时候可以锁定

不是跑完一轮或获得更高点估计就冻结。需要多个迭代、固定原名单的可重复收益、完整失败分母、原正确改错和分类别回退检查；对入围方案做独立解码重复以区分采样波动。合法交付目标为100%，内容正确性通过节点真实指标验证，不能承诺有限实验能证明所有未来输入正确。

冻结产物包含P模型/解码/模板/知识/召回配置版本、实际输入与输出身份、评价与成本、失败案例、适用范围和冻结结论。置信区间跨零不等于等效或非劣；没有新增的任意精度容损预算。

## 每轮怎样执行和交接

## 同阶段并行的准入顺序

CPU独立准备原父控制、GEPA/Reflexion指令候选和ACE供给差异；NPU只领取已准备的P任务。消费和构建是独立任务，不因其中一个外部请求未终态阻断另一轴。先跑原父控制，再按就绪次序并行候选；同策略多轨迹用于TF-GRPO的组必须实际采集。未知请求继续保留，其他独立任务可以前进。

P晋升同时看候选召回、top1/排序质量（补齐测量前不声称已有）、候选数和回退，避免单纯放宽候选集合。冻结P后S输入保持候选顺序与证据；冻结S后D输入保持候选实体与来源。教师获得目标节点的真实输入、输出、评价和对照，只修改当前节点的声明轴。
