# S节点TFRL学习与晋升协议

## 学习对象与固定条件

先完整获取现有545条S摸底结果。上游固定Q15+D5 common/OFF128 P快照，S只学习真实P最终Top3含正确意图的样本，保留原有全部候选和排序。P错误独立记录在端到端分母，不伪装成S已解决。正式训练采集沿用TRAIN7094质量合法录音视图，完成P后生成S可用清单；545不是新的TRAIN集。

每个候选记录父版本、P轨迹、音频、数据清单、卡片、提示、推理配置、rails哈希。先按节点评价，不引入D弥补来掩盖S错误。缺失/截断/无效输出计入分母，另报请求是否成功、协议有效率、槽位完整正确率及成本。

## 先诊断后生成策略

教师输入分成算法固定模板和脚本抽取的动态证据。动态部分包含失败类别统计、有代表性的失败与成功对照、原始TRAIN可追溯依据、输入知识卡和真实响应/解析、此前候选的修复与回退；不逐条倾倒全量样本。每轮最多分析5个机制维度，输出最多2项可执行策略、适用条件、反例、预期观测及放弃条件。TEST和FoldA/B不反馈教师。

对听辨错误、语义不足、标注矛盾分别保留待复核状态；模型失败不是删除样本的依据。知识卡的长度反例仅是诊断线索，必须与真实S输出关联后才能解释精度损失。

## ACE路线：可追溯的知识构建与消费更新

Generator是固定P后的真实S执行。Reflector比较正确与错误轨迹，定位知识约束、知识遗漏、信息使用或提取过程的缺口。Curator输出小幅增量ADD/UPDATE/DELETE/NONE，保留稳定条目ID、来源、父版本与退役理由。

知识构建分支只修改有合法TRAIN原文与标注支持的槽位卡表述，不新增模型自编业务知识；知识消费分支只改变使用现有证据的过程提示或组织方式，不暗中修改卡片事实。两个分支先分别测试，不将多个变化同时打包。经验中禁止样本ID到答案映射、强制gold候选及合成测试同款问句。

## TF-GRPO路线：真实同策略采样后提取经验

只有同一固定策略对同一真实TRAIN样本获得多个真实rollout，才能形成组内对照；不同历史prompt的单次结果不能冒充同策略组。奖励以合法输出和正确候选下的槽位提取为基础，使用锁定槽位指标，空槽位样本另检查无虚构槽位。全组同奖时不制造偏好；没有对照信号就保留父经验或停止该组。

复用原算法的轨迹总结、语义优势比较、组经验更新和批次合并流程，更新推理时经验库，不训练模型参数。简单改写common prompt不称为ACE或TF-GRPO。此路线在完整S错误证据到位后再选择有对照价值的TRAIN难例，避免无目的重复采样。

## 配对验收与停止

同一固定清单比较候选与父版本：同时报告精确槽位micro/macro F1、全槽正确率、条件官方SLU计数、响应/协议有效率、逐类型支持数、修复/回退数。条件官方SLU按gold对应候选离线评分，不能称为端到端SLU；D的选择尚未评估。

晋升至少要求主要精度目标改善、有效回答率不下降，并解释高支持或关键槽位的回退；只有单次小幅净增时不能宣称稳定收益。固定候选后进行既定FoldA/B一次回归；失败保留父版本，不能反向把回归错例交给教师调参。成本以总tokens、HTTP分布、聚合秒/条、四卡实例占用和CPU准备/评分分别呈现。

连续两轮同类机制无净收益时停止该机制，归档失败及成本，重新审视证据和学习对象；不能为了满载而盲目重复。NPU可并行采集后续合法TRAIN轨迹，CPU准备策略、数据和预算，只有已准备好的任务才进入NPU队列。
