# S节点TFRL学习与晋升协议

## 当前学习对象与实态

P已锁定；S只优化实际P Top3包含正确意图的样本，保留原有三个候选及排序，每次调用仅处理一个意图与其槽位。主要研究问题是：关联知识卡与合法TRAIN示例能否改善提取，而不是让模型凭标签填满所有允许槽位。

固定545条件样本是首轮策略比较集，每臂1635分支。已有S_fit1080和训练剩余3734复用原P轨迹与音频，支持无示例/动态few-shot配对；原hold仍采集并单列，不用于教师或知识来源。S_valid1080仅用于预锁策略的独立评价，evaluation_only贯穿输入、评分和反馈。TEST不参与调优。集合角色与分母不可互换。

四路当前执行C无示例、D相关完整示例、A仅改时区卡、B仅改第二例互补选择；紧凑JSON与缺省槽提示另排队。已收到外部教师两轮响应，但新增建议尚无准入候选，不能称已有TFRL精度收益。实时进度见[持续实验队列](S-Rolling-Experiment-Queue.md)。

## ACE：从真实错误到可执行增量

参考ACE（arXiv:2510.04618）的Generator→Reflector→Curator与局部增量机制。Generator保存实际模型输入、响应、解析与成本；外部教师根据有明确父版本、单位、分母的成对证据提出根因假设；Curator产出有界ADD/UPDATE/DELETE/NONE，程序合并、去重并保留经验谱系。

知识构建只修改有锁定知识库或合法TRAIN依据的卡片描述；知识消费修改已有召回结果的示例选择、作用范围或组织策略；指令修改单独版本化。禁止模型创造业务事实、样本ID到答案映射、gold运行时路由或测试同款合成问句。一次普通提示改写不称完整ACE。

教师输入由算法固定模板与动态证据拼接：提供错误类别、代表失败及成功反例、实际供给、此前修退与成本，不倾倒全部轨迹。当前最多4项单机制提案，允许零提案。外部教师只从开发机调用；每版唯一请求，未知响应不自动重发。旧batched545与新单意图1635不能互作收益上限，协议改善不能推断语义改善。

## Training-Free GRPO：组内对照后学习经验

参考Training-Free GRPO（arXiv:2510.08191）的同输入组采样、语义优势提炼和经验更新。本轮项目适配为同一动态few-shot策略、固定545样本、8个真实seed，temperature=0.7、top_p=0.9，去除seed后实际模型输入逐项一致；不是8个不同提示词，也不是扩大了独立样本数。使用外部教师分析是本项目适配，模型权重保持冻结。

奖励在首个seed采集前冻结：正确意图分支的单样本typed-normalized实体F1；合法空对空为1，无效分支为0。严格字面与官方条件SLU辅报。8次已知完整结果后计算组内均值和总体标准差，标准差为0则优势为0。标量优势仅用于挑选有区别的成功/失败轨迹；教师必须解释机制差异，再形成来源受约束的经验增量。没有对照信号不能制造偏好。

闭环为：真实组采样→锁定评分→正负轨迹对照→语义优势与经验增量→程序校验→候选真实评价→保留或回滚。当前已准备组采样与优势计算，尚未完成完整8组反馈及后续候选收益验证，因此仍是待验证的适配实现。

## 完整配对验收与晋升

主要对比C→D、C→A、D→B，各使用同545及原P轨迹。报告typed实体micro F1、单样本平均奖励、全槽正确率、strict/official、协议覆盖、修复/退化、gold空/非空及逐槽型支持数。单样本奖励均值不等于全体micro F1；无效输出保留在545分母，局部分支和整行拒绝口径分开。

双方均合法的语义子集只作诊断，不能替换主分母。按原来源组检查收益集中性，保留少数大类、空槽样本和同源录音的影响。未听音不得认定声学根因；推理失败不能作为删除样本的依据。旧545基线只作历史同ID参照，完整FoldA端到端73.31%不能与条件槽位指标直接相减。

晋升要求完整父对照的主要目标改善、回答有效率不下降，并解释关键槽位退化；单次FIT改善不是稳定泛化证明。冻结候选后在预定独立集合评价，其错例不回流本轮教师调优。连续两轮同机制无净收益则停止该机制，保留负例和全部成本。

## CPU/NPU异步执行

CPU提前完成输入、来源、预算和任务包；NPU仅消费ready任务。评分、归档、教师等待不阻塞独立实验，科学依赖保持显式。任务终态触发接续，常规监测600秒；按实际分支吞吐和每路工作小时补库存，不用无目的重复填负载。运行页原位更新，所有收益以完整结果为准。
