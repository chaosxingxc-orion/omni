# P节点输入顺序对照

## 实验目的

检验知识卡先于语音是否改善P输出Top3的意图命中。前置召回成员、标签编号和例证固定；本实验测量知识消费与输入位置的影响，不是召回算法变更。三臂fit已完成，两个位置调整均回退，保持原顺序。

## 三组固定输入

system消息保持完全一致，仅重排user消息中的原始块：

|组别|顺序|
|---|---|
|audio_first，原对照|语音→常设知识卡→动态知识卡→排序指令|
|knowledge_first|常设知识卡→动态知识卡→语音→排序指令|
|audio_last|常设知识卡→动态知识卡→排序指令→语音|

实际原P请求已核实为audio_first。原S输入也是语音先于知识，本轮不改S。三组保持块内容、卡内顺序、音频、few-shot、候选索引、模型/解码参数一致；P thinking OFF，输出预算128，输出Top3数字索引。核对JSON排列后还要验证实际chat-template的音频位置，不能仅凭请求字段顺序宣称模型输入已改变。

## 数据与执行

沿用已有质量排除清单：R01C-fit历史624条、当前有效622条；Fold B历史比较口径1078条、当前有效1075条。不新增采样或清洗，不使用按P正确筛选出的S-fit545。三组在同一622条上配对，共1866次逻辑请求；历史基线同mask为Top3 545/622，仅作辅助比较，另执行同轮原顺序对照。

使用两个既有TP4实例、共8卡，每实例客户端并发64。同一个样本的各臂保持实例路由一致，交错执行臂顺序，减轻主机和时间与实验臂的混淆。音频和检索结果复用；CPU输入准备、预算及可逆排列验证在占用NPU前完成。沿用固定镜像、运行脚本、guard和journal；任务脱离SSH，未知请求不重复发送，600秒或终态事件采集进度。

## 指标与后继

主要指标P Top3命中；辅助Top1、gold已供给条件下Top3、业务/常设类别、协议合法性、逐样本修复/回退、tokens、吞吐秒/条和HTTP延迟。报告实际资源、完成/总量及剩余时间；吞吐不当作单请求延迟。输入顺序可能改变缓存效果，效率变化不能直接解释为模型语义能力提升。

每个候选独立对比同轮audio_first。预锁准入为协议全有效、Top3严格提高、业务Top3和常设Top3均不下降。合格候选按Top3、业务Top3、Top1降序，再按tokens升序及arm名排序，唯一优胜者与原对照进入一次既有Fold B有效1075条验证。不按验证集重新挑选候选，不运行TEST，不自动替换现有P或S数据基线。若无候选通过，报告失败及逐例差异，不追加排列组合。

## 完整fit结果：保持原顺序

1866/1866请求完成，三组各622条，全部协议有效，unknown=0。固定镜像CPU评分恢复后通过，与主线程逐原始响应独立复算一致。

|顺序|Top3命中|Top1命中|业务Top3|常设Top3|修复/回退，相对同轮原顺序|
|---|---:|---:|---:|---:|---:|
|audio_first，原顺序|542/622（87.14%）|414|478|64|—|
|knowledge_first，知识→语音→指令|526/622（84.57%）|398|470|56|14 / 30|

两候选均未通过预锁准入，Fold B与TEST未运行，保持原P基线。主要下降集中在常设类别，尤其audio_last常设Top3由64降到36；这只是分层现象，尚未证明模型更关注哪类信息或音频感知退化。前置供给、文字、音频、候选和参数均保持，效果差异属于此次输入排列干预。不能据P的结果直接断言S位置效果。

同轮原顺序542/622，历史同mask545/622；逐ID修6退9，提示跨运行仍有差异。比较采用同轮控制，不把历史545直接作为三臂唯一对照，不宣称单轮结果证明所有场景的稳定规律。

资源：8卡、2个TP4实例、每实例客户端并发64；总生成跨度241.217秒，聚合0.12927秒/请求，各实例约0.258秒/请求。三臂交错执行，不虚构每臂独立墙时。三臂总tokens分别3,185,709、3,185,947、3,185,578，合9,557,234；输入tokens均3,178,686。全部完成，剩余0、ETA0。AI Core持续超过80%尚无本轮充分证据。

自动评分曾因容器/job层级与旧模块路径假设不符而失败。仅调整CPU评分运行路径后恢复，固定镜像评分容器退出0，原失败保留；没有重发模型请求。原后台driver退出1与后续恢复终态COMPLETE分开记录。

固定镜像核验全部5091份准备输入，三种实际音频位置依次后移；移除音频后的文本字符一致，BPE边界变化保留。后继S单意图与few-shot对照保持audio-first，独立验证知识作用域及示例收益。
