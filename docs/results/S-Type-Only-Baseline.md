## 错误机制的实际证据

- 部分漏报已恢复：日历表达、事件和设备角色的类型召回改善。
- 泛词和动作被过度解释为槽位：泛指天气被报weather_descriptor，调低音量动作被报change_amount。需要具体业务角色证据，而不是与类型语义有联系就选。
- 供给自身仍有冲突：静音场景卡定义把speakers列为device_type，但实际训练示例均无槽；新闻主题中的人名/地名被卡鼓励独立抽出，而对应训练示例将整个主题作为news_topic。不能把所有计分FP都归因于模型幻觉。
- 独立ASR仅用作离线反证，不能证明Omni内部听到了同样的词；ASR＋文本填值路线已按用户决定停止。
