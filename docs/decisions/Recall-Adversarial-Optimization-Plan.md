# 召回优化：对抗性分析与执行计划

## 目标与冻结边界

目标是正确意图进入供给Top5并经P保留在Top3，最终推进到后续节点。当前不换S→P架构、不扩大oracle小试、不用TEST调优、不做参数排列组合。描述库和相似问库分别优化；每条知识保持原始标签、来源和语义，禁止教师逐条生成贴合测试样本的知识。知识库构造与评估query保持来源隔离。FoldA/B为既有开发反馈，已有适应性选择需明确，不包装独立测试。

## 路线一：修正召回合并的损失机制

先分析M2的26个供给翻转和其余634个变更中的消费风险：正确标签是否原来在第4/5位、描述是否仅凭低绝对分数挤入、父候选未满时是否也有收益、哪些原来无需P筛选的n<=3变成需要筛选。用相同阈值和缓存拆解，不重新编码。

首个可执行候选是“空余位置补充”：只使用原有空余位置，保持原候选成员和顺序，描述侧沿用已冻结阈值；没有空位则回父。这是结构上不减少供给的机制对照，不保证P最终输出不退。比较新增供给和n<=3→n>3造成的选择成本。若修复主要来自必须替换的满集，教师再给基于相对证据/跨路一致性的替换策略；不得直接比较未经校准的不同路分数，不允许按query gold决定是否替换。

主线程进一步独立检查发现：14条退化中，6条正确标签在描述路排名第一，7条正确标签的描述分数高于所有新增标签，10条原P输出正确。实现先排除父已有标签，再选新标签直接替换尾部，丢弃了跨路一致支持。这符合原M2策略实现，属于合并策略设计缺陷，不能笼统称知识无效或实现bug。第二个有根据的候选是同一描述分数域内的相对证据比较：新标签只有比被替换标签更有描述支持才考虑替换，保留原头部与cap5；它仍需实测，不能保证所有标签正确或P不退化。

教师需解释FoldB正收益为何在FoldA反向，并提出可执行的触发/回退与确定TRAIN校准规则。先离线回放及逐例分析，再按预声明收益/成本选择一次P验证。原M2实验保留完成，不能把新策略覆盖到原记录。

## 路线二：让知识区分操作和关系，而非堆叠词语

描述库：重点处理on/off、增减、当前查询/给定条件换算、other业务剩余边界。只使用原始卡与合法TRAIN证据，候选变换应把操作、对象、否定和条件表达得更清楚，删除无关示例词的干扰，保持合法子意图覆盖。现key已有的排除词不能当作缺失重新补。

相似问库：先识别跨标签吸引的真实局部子簇，检查同类支持、少数类可达近邻数、source重复及业务覆盖。稳定负margin且有明确语义/标注矛盾证据的样本进入可回滚隔离候选；无权威证据时保留原文，仅调整检索权重/资格作为候选。选择代表应覆盖类内多子簇而非压成单中心。教师给筛选/保留/停止规则，不能逐条凭印象裁定或将全库低纯度硬删。

两库先各自产出策略与独立指标；不能把描述改写和问句裁剪一起跑后无法归因。每个新key只编码一次，向量模型前向优先使用已验证NPU路径，检索评分在CPU完成。

## 路线三：oracle slot上下文机制验证

复用固定60条、40slot/20empty、两个30条来源块。所有主臂同query表示、同候选合法集合、同编码模型。参考转写与正确slot均是oracle假设；gold intent只评分。保留A原query/原库、B原query+raw slots/原库、C上下文query/增强库、D原query/同增强库的解释边界。

教师必须区分三件事：slot类型泄露的业务线索、说明文本本身的作用、query与key表达匹配的作用。优先解释现有三例翻转；必要的单一诊断是value-only与type+value差异，不扫描多组合。当前拼接抽取提示会引入不相关媒体/应用词，并未实现语义角色增强。下一策略只选有证据的局部表达变换；source/target等角色需原文证据，不能凭gold intent补造。

若教师策略只通过加入答案性类型获得收益，不推进真实S架构；若两个预定块方向相反、明显损害原成功/少数类或成本失衡，不扩样追正分。记录全部修退，而非仅报净值。

## TFRL闭环与教师反馈

采用ACE的错误反馈→策略增改退役→小试→记忆更新闭环；并参考training-free GRPO的候选组相对优势做策略选择，模型参数冻结。后者是借鉴相对评价，不声称实现了标准参数训练GRPO。候选由不同根因产生，最多约3项，不以温度/k/阈值组合制造策略组。

reward分开报告供给Top3/5修退、P输出Top3修退、覆盖约束、额外调用和墙钟；未执行P则P reward=null。稳定性分块与总体同时展示，不将统计不显著等同零收益。教师输出完整算子、输入字段、并列/缺值/负分规则、拟合数据边界、最强反例、停用条件与成本；策略主审后由配置注入固定脚本。

本机上一轮ACE已完成并返回三策略，主审反馈如下：C1的角色识别、来源及排名假设需修正；C2只允许先核查官方训练语料是否提供合法新增支持；C3五句声称逐字引用但0/5通过，不直接改库。增量反馈用固定ACE模板加脚本注入7个机制代表、M2完整P结果、两库聚合和60条对照，不重复125K旧输入。要求教师逐策略保留/修订/退役，提出最多约3个不同根因的可执行候选，并解释最强反例。

105个知识键却只触发1/60 query的context-lite草案没有获准作为业务收益验证；教师需要提出对固定60/40slot有有效覆盖的、来源合法且预算有限的机制，或明确承认证据不足。不能为方便实现缩小到一个例子，也不能扩大样本追正分。
