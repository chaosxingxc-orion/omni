# 候选意图归组与节点错误归因

## 结论

知识消费前增加程序性归组具有明确依据：相同意图的解释措辞不同，不应简单丢弃解释，也不应靠模型再筛一遍。建议按合法intent_id稳定归组，保留每个成员、证据来源和不确定性；首版仅合并证据与不确定字段一致的解释变体。当前对照实验不热改。

## 已有轨迹证据

本次使用原Fold A的一份异步归档，不新增数据集或模型调用。主线程独立核验10个源码模块、归档摘要和118份响应来源，并复算P输出分类：

|P输出类别|数量|处理方向|
|---|---:|---|
|无重复意图|46|45份通过现行解析与证据校验；1份引用未提供证据，仍须拒绝|
|重复意图，仅解释不同|9|程序归组并保留全部解释|
|重复意图，证据也不同|3|保留为后继分支策略，首版不混合事实|
|截断、无法完整解析|1|不从残缺输出补造候选|

在58份结构可解析P输出中，首版归组的离线可消费资格为54份，现行为45份。这是程序契约的反事实分析，**不是准确率从45提升到54**，也不是完整1080条实验结果。分析使用字段约束镜像检查，正式schema与真实执行路径回归仍须工程验证。

## 根因与节点边界

重复候选拒绝符合当前identical_v1的整对象比较规则，尚不能称parser执行bug。模型未遵守distinct要求，同时契约可能过严。另有不同意图的解释否定自身标签，归组不能修复这种语义错误。

同一归档的13条拒绝终态中：10条来自P重复，2条来自Slot漏掉候选，1条来自Decision修改了所选Slot的实体。后两类符合现行全覆盖及仅选择契约；没有原音频和gold复核，不能断言Decision改动有益或Slot结果正确。它们必须作为独立节点优化。

## 实施与验证要求

先逐成员校验合法标签及当次来源，再归组；无效成员不能靠去重消失。唯一意图数最多3，不补足、不按重复次数投票，不把不同分支证据简单合并成共同事实。

P完成校验、Slot构造、知识检索、上下文投影、Decision及receipt重解析必须使用相同版本的分组表示。仅保存后项hash而只供给第一条解释，不符合保留信息要求。原始输出、来源及历史成本保留。

固定镜像CPU回归先验证全部成员进入下游、引用篡改被拒、旧策略兼容和同版本重解析；随后在原Fold A1080上单因素配对评估。报告候选召回、意图准确率、实体F1、官方SLU-F1、修复/退化、各节点拒绝和成本。只改善通行率不构成收益，新增下游推理费用也须计入。
