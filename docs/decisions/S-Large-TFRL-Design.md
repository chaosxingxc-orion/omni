# S阶段大规模TFRL：固定数据与可执行优化目标

## 已锁定的实验对象

探索6682、独立dev1850，均为冻结Instruct P实际top3命中后的独立来源组。每条仅运行正确意图分支，保留原rank；S只输出槽位类型。原始P分母另外报告：探索9934、dev2014。基线与每个策略使用相同固定集合，不根据S结果改成员；后续质量裁定另版本同时保留原始结果。

## 先分离无法学习的错误

当前原枚举有13条样本不可表达参考类型；TRAIN全域发现31个缺schema或卡的意图—类型组合。该类进入契约/知识库存修复，不让教师靠提示词输出禁止的类型。知识卡与标签冲突另建审查清单，当前没有授权通过教师改标签。没有值与值等于类型名不构成删除理由。

实际证据：qa_factoid下“where is yellowstone park”参考空，但当前卡及两个同实体同意图fewshot都支持place_name。audio_volume_mute的speakers存在泛指空标注与具体设备正标注；需要业务边界分析。lightup的“a little”模型输出change_amount，卡支持模糊量，实际fewshot甚至把“to eight”标空；不能将原FP直接等同能力错误。

## 指标与选择规则

令真实类型集合G、模型集合Y、协议有效v∈{0,1}。主指标E=v·1[Y=G]；数量指标C=v·1[|Y|=|G|]。集合完全一致已蕴含数量一致，不能把E和C当独立证据重复放大。另报TP=|Y∩G|、FP=|Y−G|、FN=|G−Y|；失败的参考类型全部计FN，不当有效空。

探索策略按(平均E, 平均C, macro类型F1)依次比较，同时检查协议有效率、非空完整覆盖、空集误报、无值类型召回、原正确样本退化与每意图收益。空值指类型存在但值不可恢复，区别于G为空。每次配对报告修复n01和退化n10、净收益(n01−n10)/N及按来源组的置信区间；不能以只评错例的成功率晋级。收益跨类别和dev验证，单次小片不定结论。具体容忍阈值作为冻结配置，在看候选结果前填写，不临场调门槛。

## 两条算法路径

ACE路径：教师对类别错误提出少量有源卡片组织、上下文或消费规则的增删改策略；系统核来源与实际输入变化，执行局部消融和完整回归。卡内容只能来自锁定知识及合规TRAIN证据；新业务定义不能由教师发明。

TFGRPO-style策略组路径：在冻结模型上比较多个可执行策略的同集真实评分；候选实测前优势为null。若策略标量目标采用每样本E，组内A_j=(R_j−组均值)/(组标准差+ε)，零方差优势全0；C/F1和保护指标保留独立，不让加权平均掩盖主指标回退。这是策略搜索，不是权重GRPO。若另做随机轨迹组，必须同query、同正确意图分支、同输入策略，G≥2、temperature>0、独立真实rollout；目前温度0单次基线不构成该组，三个意图也不是组。

## 输入与反馈闭环

每算法一份固定模板，通过配置注入；脚本采样动态错误代表、真实输入卡和fewshot、模型输出、类级统计与反证。正确探索query只在本地回归，dev逐例不外发。教师给根因和可执行策略，不逐例给答案。初次正式策略需完整探索基线；CPU可提前准备材料，NPU照常执行基线与dev。

只有实现并记录版本的配置桩能执行。每策略报告输入变化样本数、相同输入的输出变动、目标类别修复与退化、全量探索及dev指标、tokens和耗时。策略奖励与采样器实现、两模板适配由CPU分析进程交付；尚未执行新的教师请求，尚无大规模TFRL提升证据。
