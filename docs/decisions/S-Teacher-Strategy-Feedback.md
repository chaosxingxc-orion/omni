# 教师策略执行反馈与下一轮调整

## 已完成与结论

ACE和TFGRPO均在本机完成真实外部教师调用，模型参数冻结。总输入114374、输出55679、总170053 tokens；其中reasoning48193。两次并行请求各185.03和888.52秒，不能把相加时长当总历时。货币成本未知。

ACE产出一个共同知识重排候选；TFGRPO已编译一个不同重排候选及一个选例候选。选例候选与既有static examples-only的1635个实际请求完全一致，直接复用结果，不追加NPU请求。当前没有实际group-relative advantage或系统级TFRL收益的证据。

## 选例策略的真实反馈

静态角色覆盖替换query近邻示例，固定545/1635完成。学习476：exact269→265、TP459→455、FP171→200、FN93→97，非空完整覆盖253→252。实际换例的50个正确意图分支exact20→17、FN16→23；其余426个完全相同packet exact249→248，但FP146→172。不能把全部波动归因于选例。

结论不是放弃few-shot或共同边界，而是现有静态选择不等于高质量信息供给。需要检查示例与当前表达的相关性、角色差异以及缺省状态。只要求候选池包含共存/泛指例，也不能保证最终两例展示它们。未来候选先看最终模型输入是否真正不同；池子变了但实际例子没变不算新探索。

## 两个被拒策略存在可恢复操作

主线程对TFGRPO S1、S2全部operation重新运行现有严格validate_ops，均通过来源、同意图范围、受保护断言和顺序一致性检查。

- S1策略级sources比操作来源并集多两条本组合法保护来源，操作本身没有缺来源；选例预算为null，但策略没有选例操作。
- S2仅因选例预算null被拒，同样没有选例操作。

这是表示契约与操作类型不匹配，不应统称教师无有效策略。原始strict拒绝回执保留；后继独立适配可在“无选例操作”的条件下将null规范成空配置，操作不变；策略来源的额外合法保护引用保留在审计中。不能把缺来源、跨意图来源、非法预算或自造断言同样放宽。兼容适配尚需物化验证，未批准它们推理。

## 当前算法空间过窄

已可执行候选主要是14条已有断言的顺序调整。这有明确作用范围，但不足以宣称覆盖了知识构建、消费和模型能力优化：教师不能在现契约中提出有来源支持的定义重写，示例运行选择又固定为静态choose_two，部分操作最后落到同一请求。

下一轮应分别保留可执行的优化通道：

1. 知识组织：基于既有业务证据进行类型视图投影、共同边界组织、争议信息移出运行输入。改写需要对照来源审阅，不允许自由新增业务定义。
2. 知识消费：同意图真实TRAIN示例的语义相关性与角色区分共同选择。不得按当前query的gold选择、不得把未标类型当可靠负例。
3. 提示词：强调类型存在与值可恢复分离；合法类型不必填；类型不确定不是未选集合的补集。此通道与知识正文分开编译。

每条策略必须能说明改变哪些模型可见内容、解决哪类错误、保护何种能力。避免把审计元数据变化当成策略创新；也避免让测试/报告集标签进入反馈。

## TFRL学习闭环

ACE把成组错误及反证更新为来源支持的可执行知识操作；经实际rollout验收后才保留增量记忆。TFGRPO适配应对同一冻结父生成具有实质差异的策略组，在相同学习样本上获得多维配对反馈，再进行组内相对比较。

每个策略保留奖励向量(Exact, type-F1, 非空完整覆盖, -FP, -FN, 协议有效率, -未决负担)，不以任意单分掩盖漏提增加。数据分母固定；gold意图分支用于S评价，另两分支无金标不能借用gold类型。选例重复策略复用结果但不能当独立重复实验。待真实rollout后才能计算advantage；按策略搜索实现说明方法身份，不冒称执行了参数GRPO训练。

下一轮固定模板应明确报告字段形状、无选例预算的表达、策略来源与操作来源的关系及不同操作组合的语义。动态反馈只含学习476的成组机制、必要代表轨迹、来源卡和配对反证。思考8192只是提示目标，本次TFGRPO实际40558；未知服务端硬限不能假称已约束。
