# S节点完整探索基线

## 实验目的与设置

锁定大规模S槽位类型识别基线，作为后续知识构建、知识消费与提示词TFRL候选的共同对照。模型为Qwen3-Omni-30B-A3B-Instruct，TP4、每实例并发64、输出上限512。探索集6682条、独立开发验证集1850条，均经冻结P真实推理且正确意图进入top3；每条仅运行正确意图的原分支。输入不提供当前金标槽位，S不填值，D承担值填充。

## 资源与效率

三个4卡实例分片完成探索，全部任务可脱离SSH运行，终态持久保存，未知请求0。每实例各分片摊销0.541–0.590秒/条，此数为吞吐折算，不是单请求延迟。累计29487294 tokens（输入29312478、输出174816）、4.17609卡时。不能把跨主机时间戳拼成整体墙钟，也没有AI Core持续超过80%的证据。

1850条独立验证已按1000／850两片派发A/B，尚未汇总验证结果；探索完成不代表完整实验或系统级目标完成。验证不发给教师逐例调优。
