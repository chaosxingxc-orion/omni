# 子智能体模型路由

仓库通过 [`configs/agent-model-routing-v1.json`](../../configs/agent-model-routing-v1.json) 固化子智能体职责与模型分工。工程开发、固定脚本和配置、测试实现以及文档生成使用 `gpt-6.1-terra`；样本分析、统计结果和 bad case 根因分析使用 `gpt-6.1-sol`；任务规划、结果评价和重新规划由 Astra（`gpt-6-astra`）负责。

模型路由是准入条件。调用前必须记录请求模型、实际模型身份、任务哈希和交付目录；实际模型不可用时阻塞该职责并记录原因，不能静默换成其他模型，也不能把“完成”消息当成交付。每项工作仍需落盘 `REPORT.md`、结构化 `result.json`、文件哈希和测试证据，主线程核验后才能合入或调整实验队列。

该配置只约束 ChatGPT/子智能体协作，不改变 NPU 推理模型、实验预算或业务评分口径。NPU 实验、CPU 分析和外部教师调用继续按现有队列与断点协议异步运行。
