# 同机 HF/FSDP4 与 vLLM TP4 训推精度对照

先用同一组 0–3 卡顺序执行正式训练 worker 与正式推理精度 overlay。输入为历史验收中失败的真实 P 录音、4,656 个原始提示 token 和 10 个原始动作。训练端使用实际 BF16 全参数分片前向、零初始化 LoRA、无梯度、无更新。旧推理实例已排空退出，旧训练主机停派发。

| 实际前向 | 动作数 | 最大单 token log-prob 差 | 整段 log-prob 和的绝对差 |
|---|---:|---:|---:|
| HF/FSDP4 与 vLLM TP4 有音频表示控制的 teacher-forced prefill | 10 | 0 | 0 |
| HF/FSDP4 与 vLLM TP4 有音频表示控制的缓存 decode | 10 | 0.1051693894 | 0.1074636003 |

第 8 个动作的原始上下文位置为 4662（零基）。四个 HF rank 的 logits 摘要、全词表 argmax、一共 98 个边界摘要一致。受控 TP4 prefill 的 98 个观测行与 HF 全部相等；decode 首次可见差异为 `1.post_norm`。本对照里 vLLM 尚未与 HF 比较全部动作的全词表 argmax，音频出口替换也只用于隔离语言端；两者都限制了结论范围。

已深入解码块索引 1 的注意力：第 8 个动作的 Q 四 rank 逐值相等，但同一段 4,663 位置的逻辑历史 K/V 从位置 12 就不同。每 rank 的不同元素数量：K 为 786/1193/1136/1517，V 为 2690/2965/2242/2939，注意力输出为 95/58/64/53。注意力接收不同的操作数，当前不能把它的输出差异直接归因于 SDPA。亦不能把已复现的差异归因于八卡切分，因为这轮两边都是四卡。

位置 12 的初始 prefill 复验已完成：首块解码入口、norm、QKV、注意力和输出投影均逐值相等。首个差异是首块 MLP 输出，每 rank 16/2048 个元素，最大差 0.0001220703125。前两块该位置的 K/V 在同一次请求中写入前与读回逐值相等，表明该处缓存保存了上游差异。自然路径起始 prefill 为 4,656 行，强制评分为 4,666 行；行数变化触发何处的数值差还在逐级确认。专家路由与计算探针已接续；定位后定点修复，再验证层、整模型及更新态。

工程启动已处理两点：HF 诊断需要复用正式入口的宿主 passwd/group 只读绑定和通信接口，四 rank 首次全归约验证通过；已排空的 vLLM 设备使用原 guard 启动同一封存前向，不要求伪造或恢复原服务。两个诊断均已成功退出。P 真实优化器更新仍为 0。

MoE 的实测边界进一步缩到 gate/up：两种 prefill 的路由 logits、8 个专家 ID、权重和目标行的 gate/up 输入相同。Rank 2、3 各有 1 个 gate/up 结果不同，对应激活和 down 输入也不同。Rank 0 的 down 结果有 151 个元素不同，combine 后为 16 个。其余 rank 只发布零贡献，不能据此认定 down 已对齐。完整操作数回放按实际专家和路由位置关联两次前向，再分离前级传播、矩阵行数和行位置。

两次实际前向中，发生 gate/up 差异的专家 112、28 的矩阵行数不变（622、949）。由于组内排序变化，目标行分别从 173 移至 470、从 916 移至 309（零基）。四 rank 全宽计算的操作数重放均复现实际目标行输出。在同一矩阵移动这行能复现偏差。专家 112 对应的完整 down 输入差 1 个元素，输出差 151；固定同一行输入时，两种位置下没有重现 down 偏差。专家 28 的 1 个 down 输入差异未改变最终 down 行。这条证据定位到 gate/up 的行位置敏感性，无法确定 CANN 内部累加顺序。

沿用 HF 动态分派实测 和 独立算子对照：实际 HF grouped 分派在当前镜像下最终消费逐专家 BF16 mm。历史 padding 和 FP32 改造曾偏离原 BF16 参考。当前保留旧路径和全宽权重、路由次序、激活舍入与 KV/prefix cache，在同一模型镜像重放 BF16 grouped matmul 和 FP32 的纯行置换。两个出错专家在各 11 个位置均未复现偏差。

第 0 层真实消费通过了位置 12 的 gate/up、激活、down 与 combine 逐值回归；第 8 动作的整模首差从 `1.post_norm` 移至 `2.post_norm`。只改 vLLM 时，原先与 HF 完全一致的 prefill 退化到 0.175921/0.196074，因此拒绝单端补丁。以独立 HF 对照、两端同一实现验证候选，第 0 层切换后 10/10 prefill 分数、98/98 边界与新 HF 一致；缓存解码对新 HF 仍差 0.104818/0.125171。对旧 HF 的差异保留作变更代价。该候选只验证前向；梯度、吞吐、自然音频与更新态都需按 历史三阶段判据 独立验证。

全 48 层扩展完成同组四卡顺序验收。10 个受控音频 prefill 分数和 98 个观测边界再次与 HF 完全相同；带缓存自然解码 10/10 动作齐全，最大 log-prob 差 0.1034198552，序列差 0.0843615623；两条路径各 0/10 个 raw top-1 ID 变化。位置 12 的前两块未观测到差异，目标预测首差移到 `3.post_norm`。第 3 层的实际 Q、逻辑历史 K/V 和 attention 输出对照已启动。相比旧 BF16，诊断 HF 的单次前向从 6.23 s 到 8.79 s，含观测开销，尚非稳定吞吐结果。整模验收未通过，候选不得用于 P 正式训练。

第 8 个动作处，第 3 层四个 rank 的 Q 完全一致，逻辑历史 K/V 首次在位置 4657 不同。回溯该位置，第 2 层 rank 1 的 Attention 输出先出现 1 个不同值（绝对差 `3.814697265625e-06`），随后四个 rank 的 `2.o_proj` 各有 22 个不同值（最大差 `3.0517578125e-05`）。前四层在该位置的当前 K/V 和同一请求的后续读回一致；这条证据只覆盖单个位置。排除更早历史 K/V 传播，需要在该位置对比第 2 层的全部 4658 行逻辑 K/V，再依据 Attention 的同操作数对照 独立复现单行与因果 prefill 之间的差异。该诊断仅记录影子输出，实际模型仍消费原输出。

同操作数对照已封闭：4/4 rank 的目标行 Q 和全部 4658 行逻辑 K/V 逐值相同。真实缓存 decode 与在 prefill 操作数上重放的单行 SDPA 逐值相同；截到目标位置的 4658 行因果 prefill 也与单行逐值相同。只有原始 4666 行因果 prefill 在 rank 1 的局部 head 5/channel 37 产生差异（`-0.000720977783203125` 对 `-0.00072479248046875`）。已复现的首差由 Attention 的执行形状触发，不能归因于该位置的分页 KV；现有对照同时改变了 Q 和 K/V 长度，尚未分离 mask、形状与底层分派。探针独立记录真实及影子计算，不替换业务输出。受控样本仍保留 10/10 原始动作。

保持完整 K/V 长度 4666 时，原隐式因果 SDPA 与完整显式 mask SDPA 逐值相同；同一显式 mask 的单行调用仍复现 rank 1 的差值，修改被 mask 的未来 V 不改变完整调用结果。现有证据支持 Q 形状相关的 SDPA 数值分派，未测定 CANN 内部的归约指令。历史 TND FIA（BF16 输入/输出，右下因果掩码）在这组实际整段/单行操作数上 4/4 rank 逐值一致。相对当前单行输出，FIA 每 rank 有 20–25/1024 个不同值，FP32 小算子影子对照有 131–254 个；两者都不是原输出的逐位替代。先将 FIA 作为第 2 层两端同一源码的无梯度诊断候选，保留 vLLM 实际 KV 读写；是否能复用到全层，以真实逐层轨迹和模型分数为准。

第 2 层双端候选闭合后，位置 4657 前四层的观测边界都逐值一致，原先首次不同的 `2.attention.out` 和四 rank 的 `2.o_proj` 均归零。受控音频 prefill 仍为 10/10 log-prob、98/98 边界与 HF 逐值一致。缓存 decode 的首个可见边界移到 `5.post_norm`，最大 token 差 0.0735056400，整段差 0.1136242917（第 1 和第 8 个动作超过 0.01，全词表 raw top-1 0/10 翻转）。相对只调整 MoE 的基线，最大 token 差下降，整段差上升。按同一候选批量扩展全部 48 层，仍使用四卡顺序对照，同时扫描起始 prefill 的全部 4656 行与前八层算子；候选保留无梯度限制。
