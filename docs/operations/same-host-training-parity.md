隔离实验已正常退出：同机同四卡、每个请求冷命中 0、按原 seed 逐个生成，再完整 prefill 评分，HF 对包括 1 条已改变回复在内的全部新动作独立复算。8/8 条、86/86 个动作的 vLLM 完整 prefill 分数与 HF 逐值相等。逐 token 解码仍只有 4/8 条通过：第二条录音 3 个 seed 最大单 token 差 0.0127086，另 1 个为 0.8318183。第二条录音的 10/11 token 两种真实后缀，HF 的 227 个边界摘要对比显示，32 层音频、拼接、语言第 1 层 post-attention norm 之前的共同提示均相同，首次可见差异是第 2 层 input norm 的共同提示。此前不同后缀分配在不同 FSDP rank；已派发同 rank 逐次消费两个后缀、捕获第 1 层真实路由与专家输出的对照。不能据此预判首差算子。

同 rank 的第 1 层定点对照在四卡分别复现：共同提示的 Attention 输出相同，router logits 在 8 个位置不同；top-8 专家编号逐值相同，归一化后的权重只在位置 2491 不同，专家输出和 MoE 输出也只在该位置不同。在真实路由输入和权重上复算原 BF16 linear 精确复现两臂；相同的目标输入行单独计算与较长序列矩阵运算有 1 个 BF16 元素不同。沿用历史全宽 grouped 投影方法，两个序列长度下全部 5237 个共同提示位置的 router logits 精确相等，目标行单独计算也精确相等。该实验只证明此处首差与矩阵行数有关；48 层训练侧及推理侧采用同一候选，由原始批量请求回归后再判断整模是否通过。
