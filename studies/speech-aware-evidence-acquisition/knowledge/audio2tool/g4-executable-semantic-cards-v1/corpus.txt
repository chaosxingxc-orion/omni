AUDIO2TOOL EXECUTABLE SEMANTIC-CARD CORPUS

OUTPUT CONTRACT
Return only one JSON array. Every element must be exactly {"name":"registeredToolName","arguments":{...}}. Use an exact registered tool name, an exact legal argument-key set from its card, and JSON values with the public types and constraints. Copy task values only from the speech or its same-core observation. Never copy a value from a synthetic example.

CARD USE
Choose a tool by its operation meaning. Use Avoid guidance to reject nearby tools that share nouns but perform a different operation. The construction summaries contribute only observed legal argument-key sets; no source utterance, sample identity, transcript, call label, or argument value is available to this builder.

TASK-WIDE EXECUTION CARDS

TASK CARD multi-call-ordering
For multiple supported actions, emit one call per action and preserve the spoken action order. Do not merge distinct actions or add an unrequested call.

TASK CARD correction-resolution
A final correction supersedes the earlier value or action. Emit only the corrected call state and do not retain a superseded argument.

TASK CARD implicit-end-state-resolution
For an implicit request, select the operation that reaches the desired end state. Do not invent an argument value that was not spoken or observed by the same core.

TASK CARD multiturn-carryover
Carry forward only relevant facts explicitly established in earlier user turns, then apply the final user request. Never use future turns or invented assistant facts.
