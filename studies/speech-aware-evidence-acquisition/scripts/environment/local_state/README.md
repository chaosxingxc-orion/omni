# 本地持久化实验状态

此工具为 Ceph 客户端故障期间提供容器内的本地状态视图；它不授权实验、不删除旧租约、不自动重发请求，也不修复主机内核。

`prepare.py stage` 在持有原共享 `generation.guard` 时复制指定的窄目录，校验前后文件哈希，并在本地 ext4/XFS/Btrfs 执行文件和目录 fsync。模型、数据和历史来源仍从只读共享目录读取，不重新制作数据集。目标必须是 `/var/lib/omni-local-state/` 下的新目录；失败输出保留，不能覆盖重试。

`mount-arguments` 输出 Docker 参数数组：共享数据根只读，指定状态目录本地可写，`locks` 本地可写，但 `generation.guard` 单文件绑定回原共享 inode。共享旧 `flight.lock` 保留，阻止旧启动器误入；本地副本也保留，只有完成 boot、进程、请求及响应核对后，独立恢复步骤才能归档它。

迁移前后必须满足：

- 旧执行者已终止，所有请求结果已核对；未知结果不自动重发。
- 所有写入路径均已枚举；只读挂载出现拒写时先修复路径，不能把整个共享根重新打开为可写。
- 新会话凭证来自当前实际服务进程；注册锁继续使用原共享单文件。
- 新执行器、观察器和后续队列使用相同本地状态视图，不能把共享副本当成最新状态。
- 本地盘是主状态。归档应由开发机异步拉取，按哈希和提交水位记录；未经验证的共享副本不能用于断点恢复。本工具尚不实现异步归档或断电恢复验证。

正式验证：`pytest tests/unit/test_local_state.py tests/unit/test_generation_lease.py -q`，通过固定 saea 容器执行。单元测试通过不代表生产恢复、Docker 嵌套挂载或整机重启恢复已验证。
