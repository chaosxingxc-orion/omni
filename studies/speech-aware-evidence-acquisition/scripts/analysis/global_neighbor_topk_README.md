# Global neighbor TopK

`python scripts/analysis/global_neighbor_topk_runner.py --config /external/config.json` reads SHA-256 pinned external JSON and NPY files and writes a new output file. The caller creates the output directory and computes the source groups before running. Paths are provided by configuration. No model or encoder is invoked.

Members JSON is an array in matrix column order, each with `intent` and `source_group`; queries JSON is an array in matrix row order, each with unique `sample_id` and `source_group`. Group values must share one namespace across both inputs. The query source group is excluded from candidates in both modes. Source-distinct selects at most one member per group; raw retains duplicates. Scores must be finite cosine values. Ties follow matrix column order; labels are ordered by their first (highest cosine) neighbor. The returned label list varies in length; no probability or calibrated direct decision is provided.

Separate identity and gold upstream; neither query labels nor gold are inputs to this interface. The caller is responsible for group construction, verifying its exclusion policy, and recording provenance. Existing frozen rankings from other implementations are not regenerated by this tool.
