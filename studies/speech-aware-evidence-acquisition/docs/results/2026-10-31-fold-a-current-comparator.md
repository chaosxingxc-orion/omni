# Current-A0 Fold A agreement comparator

The older held Fold A comparator uses the earlier port model, the v2.2 module lock and an earlier sampling layout. It is not the source identity for the current natural-end Agent. Preserve it as history.

`scripts/flights/nx/fold_a_current_comparator.py` derives a new, never-flown comparator from the actual completed A0 flight source. It requires the successful full Agent campaign, its exact clean source commit, matching model-fragment bytes and completed Fold A retrieval preparation with all artifact hashes rechecked. Source baseline, experiment and model hashes are recorded with both completion-receipt hashes. No actual comparator is published until those prerequisites exist.

The transform keeps the current c17 sampling program, Solver recall/ranker/fuser, shared stores, centroid keys, model and service session. It replaces only Fold B query/roster bindings with the complete Fold A inputs and disables the agreement component for its own bootstrap. The module compiler supplies the component's agreement-free Perception fields, and the complete module must pass `verify_declared_module`. The Solver vote retrieval used by the agreement builder is checked unchanged apart from the query binding. Disabling agreement changes the bootstrap Perception k according to the module lock; this is not a change to the later A0 evaluation or to its Solver top-20 vote.

The new cell allows only `check`, remains held, carries no admission receipt and is never flown. Inherited c17 structural ceilings do not authorize contacts. The standard self-excluded agreement builder can then use this cell's current model/dataset/config identity without opening a model session. Actual A0 evaluation retains the agreement component and requires separately registered supply and flight configuration.

Formal network-isolated validation passed 11 tests: real module compilation and composed-config verification; preservation of source objects, shared stores, Solver recall and serving identity; refusal of absent/zero/nonhex pins and module drift; publication against completed source fixtures; source-commit, model and artifact drift refusal; no overwrite. Early negative tests used the wrong exception class, then isolated writer fixtures lacked an admitted-component record and port pins; these fixture defects were fixed without changing production gates or historical files.

Remaining execution: wait for complete Agent and Fold A retrieval outputs, publish and commit this comparator, build/verify the agreement table using the standard builder, close preparation ledger rows, then register the current-A0 Fold A comparison and supply. These steps precede the D0/A0 gain lock; no TFRL promotion is implied.

## Explicit queue successor binding

The optional `--parent-binding` JSON selects a new completed A0 and retrieval chain without rewriting historical defaults. It pins the source specification hash, A0 commit/run, retrieval commit, and confined completion paths. The queue schema and identity must match; A0 campaign, paired read, encoding and retrieval must all be done with exit zero. Actual source checkout, full rows, final score surface, model bytes and vector hashes retain their original checks. The output records the binding and observed queue-state hash. This is still model-free preparation, not evaluation admission.

Formal network-isolated regression: 20 passed in 33.12 seconds. New successor fixtures remove historical parent directories and cover successful derivation, failed queue jobs, nonzero exit, queue identity mismatch, source commit/run drift, retrieval commit drift, specification drift and path escape. No real comparator was derived by these tests.

Public packaging includes the historical held source configuration needed for reproducible model-free tests, retrieval input builder, and exclusive atomic publisher. The public model fixture omits the private materialization root and uses the standard data-root fallback; it is not a byte-identical live runtime receipt or flight admission. Parent derivation still requires source/destination model bytes to match. Initial public tests exposed a missing atomic publisher dependency (26 failed, 15 passed); after including that dependency, 43 tests passed in 26.93 seconds before path sanitization.

Final public model-path sanitization regression: 20 comparator tests passed in 23.49 seconds.
