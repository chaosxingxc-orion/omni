# P与Slot节点提示优化依据

## 结论

下一轮只准备P-only和Slot-only两项独立对照，保留Decision、冻结知识库、v4g和已有恢复策略。当前完成错例证据分析，尚无新提示的线上收益；首版配置因父模板不匹配已退回修正，未合main、未准入。

## 证据范围

从同Fold A1080的既有来源中选取每节点6个机制错例、3个正确对照，共27个节点contact、26个唯一样本。实际请求payload、终态响应及676项知识供给内容hash已核对。Slot优先复用前次响应，其他只按request ID定点读取；没有全trace重扫、模型调用或重新评分。主审核34份输入/分析产物摘要及6份提交配置摘要。

这不是随机抽样，不能用其比例估计总体收益。未复核原音频，模型在distinction中的措辞不是真实转录，不将语义混淆自动归为声学错误。

## P：让候选代表实际请求

全量96条正确意图未进P，其中49条已供给对应boundary。定点错例显示：复述卡片定义、同一intent重复占位、用否定理由支持候选、提到邻近解释却未保留它。供给存在不等于模型已理解。

候选提示强调操作、对象、方向/状态与原音频的一致性；一起使用卡片activation、exclusions和limitations；在原最多3个候选内保留有依据的歧义，禁止用重复或泛候选填满。风险是过度扩候选挤掉正确项，或增加输出长度，必须检查原正确样本及截断率。

## Slot：区分角色定义与实际说出的值

378条最终intent正确而实体非全对。前次normalizer受影响的285条中，有98条intent正确且仍实体错；这是受影响子集，不能代表全部378条。

定点响应与真实槽位合同存在冲突：角色泛词被当作名字、请求类别词被当作履约方式、类型标识直接成为filler。部分错误在v4g后仍残留，具有改善最终结果的可能。跨候选出现相同实体本身合法，当前不能证明复制或候选污染就是根因。

候选提示强调：合法类型和卡片binding不是必填证据；从原音频提取该语义角色的实际值，不能拿类型名、卡标题或未指明的名字替代。同时明确保留日期、时间、关系、模式和描述等普通词表达，避免过度保守增加漏抽。无依据时保留候选行及合法空entities，不制造值。

## 为什么暂不改Decision

有60条正确候选可达但最终选错；定点分析可确认候选存在，不能确认模型忽略了哪一句音频。全量Decision改正P首选60条、改错16条，净增44。当前没有足够证据支持强制首选、按实体数决策或第三项独立提示变更。

## 实验绑定与验收

首版基于compact P和reference B，但真实完整coverage父配置的正常节点仍用原P OFF与Slot shared模板。不能把恢复子请求或HOLD候选模板当作正常基线；已要求原执行者基于真实父配置重做纯语义delta，保留其他字段及恢复提示，不等待新造开发集。

每项先用既有机制样例和正确负控检查行为，再用同Fold A1080全分母比较。报告有效回复、Intent、官方SLU、Strict、错→对/对→错、调用和tokens。P另看正确意图候选可达性；Slot另看normalizer前后实体TP/FP/FN。仅减少最终已被清除的错抽不算最终精度收益。两项单独验证后才决定是否组合，TFRL仍后置。
