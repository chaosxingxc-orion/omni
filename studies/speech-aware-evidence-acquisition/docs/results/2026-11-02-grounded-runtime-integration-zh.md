## 已实现与验证

分批规划、来源读取和执行器现已进入共享 rails 包，保留原 analysis 导入/命令入口。新增显式 grounded 注册 schema，绑定每片消息摘要、TRAIN anchor、执行摘要、输出上限、运行身份与完整来源成本；旧 TF-GRPO schema 保持原约束。FlightRuntime 的来源预检、原生 FIT、分片派发、原生账本恢复及 artifact 封存已接线。

103项固定镜像 CPU 回归通过，覆盖共享 adapter/dispatcher、历史导入、原生恢复与FIT；随后新增任务准备/注册、包装后输入超限和封存回归组合47项通过。两组合有重叠，不相加。测试中的网络/tokenizer endpoint为替身，不能当作真实native FIT。

恢复测试使用子进程明确退出：已落盘响应通过 NativeContactReplay 读取，无新增生成且保留前驱成本；未知请求拒绝发新请求。学习器交接失败也可从原生响应恢复。分片输出固定为中间产物，不写 candidate.json，不声明新方法精度收益。
