# PSD v2 回答恢复与算法适配结论

## 已完成与未完成

新首发准入支持已合 main `2733329d`，固定镜像17项单测通过、5项归档 fixture 测试跳过；两臂真实1080注册资产的隔离 CPU 准入和通用启动器绑定校验均通过。最终完整 release 7511文件验证通过，已交原启动进程执行正式准入和推理启动。隔离测试不是正式模型实验：目前尚无首请求证据，两个新 run 各0/1080，吞吐和ETA未知。

Decision 独立配置入口 `4c1039ff` 已合入，固定镜像16项测试通过。覆盖恢复正在独立分支实现，未部署，不宣称100%有效回答已经实现。

## 应优先修复什么

v2 已具备重复候选归组、锁定知识去重和 Decision 只选ID后程序组装。旧系统的重复候选拒绝、Decision 实体改写拒绝不能当作当前仍然存在的全部问题。

现版仍有真实限制：Slot 任一候选缺失会导致整份结果被拒绝；answer-only fallback 仅处理有 thinking 答案预算的空文本长度终止，不能修复普通格式错误、非空截断、Slot缺项或关闭thinking的节点空答。

先保留已合法返回的 Slot 分支，再用原音频、候选知识及明确错误反馈定点补齐缺失分支。不要整题重跑，不默认空槽，不缩小原候选集合冒充完整回答。最终结果必须能从全部原响应重放重建，恢复请求有独立身份、预算、费用与断点记录。来源异常和UNKNOWN进入单独恢复流程，不自动重发。

历史旧B的141个Slot覆盖拒绝中，136个请求原本包含正确意图，其中133个已经返回正确意图分支。这说明整份弃答有明显损失机会，但不证明这些分支的实体正确，也不预测新v2一定恢复133个正确答案。首批新轨迹需重新核查。

## 三个方向与四种算法

|方向|当前可复用能力|接下来要完成|
|---|---|---|
|知识构建|知识卡编辑、原始证据绑定、快照发布的既有实现|适配v2，基于原定义生成独立候选卡版本，固定召回/提示比较父库与候选库|
|知识消费|多库、节点供给、候选条件关联和程序去重|把召回/排序/过滤/预算变化绑定为可复验策略，明确作用节点|
|激发理解能力|P、Slot、Decision独立提示及thinking配置|算法候选编译到实际节点输入，保持节点职责与最终评分一致|

|算法|保留的算法机制|v2适配重点|
|---|---|---|
|TF-GRPO|真实同题多轨迹相对反馈；参考summary→advantage→group update→batch update|新基线真实分组与节点目标；融合式单次候选与参考链分开报告|
|GEPA|轨迹反馈变异、父代池、minibatch及完整selection评估|从旧Solver提示迁到P/Slot/Decision明确合同，优先复用已实现Decision入口|
|ACE|Reflector→Curator、增量整理、冲突与重复处理|开发态优化知识卡内容并发布候选快照；运行态只读选定版本|
|Reflexion|有反馈的反思记忆与后继尝试|区分同题重试和跨题迁移；与相同预算无记忆恢复对照|

算法文件存在不代表四算法均已接通PSD。旧joint候选和不同子集分数不能横向排名，也不能替代新基线。

## 排队与科学依赖

已整理27个规划节点、50条依赖：当前双臂启动；CPU首批漏斗分析；答案恢复及同名单复验；三方向分别配对；Fold A选型、Fold B冻结确认；稳定基线后四算法探索及最终完整测试。该图是研究依赖，不是已注册的native执行队列。

恢复实现与算法素材准备现在并行；CPU评分不阻塞无依赖的NPU任务。有效回答率与Intent/SLU/strict分开；完整名单保留失败分母。知识卡优化允许开发态版本化，不能改标签定义或将评测答案写进知识卡。模型运行时不临时写权威库。

## 交付与限制

完整私有报告已交付并审阅，含源码位置、历史fixture索引、数据身份、算法入口、预算建议、回归判据和依赖。研究图中显著性门槛是分析建议，尚未作为运行准入规则；不能因新增研究门槛拖延启动。恢复预算也须按实际实现确定，不能默认为旧6480调用预算足够。

正式汇报采用完成/总量、秒/条与单样本延迟、资源、ETA、主调用/恢复/FIT费用；利用率来自运行窗口实测。当前没有证据证明新实验已满载，也没有新v2精度收益结论。
