# 外部教师候选语义审查

## 当前结论

本机ACE与Reflexion各一次调用共返回8个候选，全部编译通过。编译验证来源与协议，不能证明知识正确或效果提升。当前仅将原文Reflexion实体构造记忆投入固定80条配对诊断，未晋升为默认策略。

| 算法/候选 | 判断 | 主要依据与风险 |
|---|---|---|
| ACE 0：实体来源 | 可诊断 | 多余实体与知识说明同词，但反思器无音频，不能证明是复制；需防止删除真实同词实体。 |
| ACE 1：主题通知 | 暂缓 | 一组新闻通知不足以支持全部天气通知归新闻，也不足以定义闹钟边界。 |
| ACE 2：关系词跨度 | 暂缓 | 有遗漏证据；将to/by/at及时间方向词普遍纳入跨度需要反例验证。 |
| ACE 3：非行动空槽 | 暂缓 | 从局部空槽标注推出删除真实时长、应用、活动，缺少充分语义边界。 |
| Reflexion 0：操作对象比较 | 暂缓 | 多候选比较合理，但单候选禁止越界会改变旧系统纠错能力。 |
| Reflexion 1：保留关系词 | 暂缓 | 与ACE 2共享机制和证据，不能视作独立复现；低分不证明音频没说关系词。 |
| Reflexion 2：语音实体构造 | 已启动诊断 | 源轨迹出现持续遗漏、姓名合并和措辞不符；绑定非穷尽、复姓名误拆是明确风险。 |
| Reflexion 3：合同角色定型 | 暂缓 | 类型与词形混杂，部分教师“得分更高”解释不被实际交付分数支持。 |

## 配对验证

复用固定80条TRAIN开发样本，教师16组与开发80及选择80在查询、话语、音频身份上均不重叠。历史知识可能见过开发样本，不能称全系统未见集。TEST不参与选择或调优。

配置为2卡TP2、并发32、64K上下文。每条共享一次Perception，再执行原文记忆Solver与原Solver，正常240次生成，FIT另计；P/S均thinking3072与answer reserve1024。原知识、模型、解码、后处理固定。自然语言记忆不能保证只影响实体，必须同时报告意图漂移。

检查官方SLU、意图、实体F1、strict、配对修复/破坏和实体FP/FN。尚未获得首完整样本，不报告收益、秒/条或ETA。生成和评分由持久队列接续，600秒或终态观察，本机异步归档。
