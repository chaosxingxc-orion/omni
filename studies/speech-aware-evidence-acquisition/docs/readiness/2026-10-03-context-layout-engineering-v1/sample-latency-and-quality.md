| Measurement | Boundary and interpretation |
| --- | --- |
| Mean across all samples | Arithmetic mean of admission-to-settled-workflow elapsed seconds; retain every sample |
| First sample | Admission index zero in the frozen executor roster, regardless of completion order |
| Mean excluding first | Exclude exactly that predeclared first sample; report its cost separately |
| Admission waiting | Batch dispatch start to sample admission; report separately, including per-sample values |
| Batch dispatch wall / count | Dispatch start to last recorded settled workflow, divided by count; a throughput measure |
| Node measurements | Original server prefill/decode and client transport means/p50/p95, and input/reused/evaluated/generated tokens |
