# Complete-system evidence-path pre-registration

Root registers an owner-authorized bounded SLURP continuation before any
family model, tokenizer or runtime tool contact. F10 is complete and its
representation variant is closed. Use the original incumbent minus-R01
knowledge. Semantic-delta and VAR-2 remain closed.

Run the existing four-row engineering smoke, a fresh 625-row control, then
a matched 625-row tools policy. Both full arms use the same problem-directed
Reviewer prompt and native program, with up to three Reviewer iterations
and a reserved final report. Only the tools policy exposes the existing
source-bound semantic target lookup in Reviewer. Planner decides routing;
Solver retains answer authority. Native tool observations enter their
recorded role history and the remaining complete episode. No forced tool
call, lexical query from raw review prose, new responding model or private
executor is introduced. Do not change policy during either full arm.

The unit of efficacy is the complete delivered episode. Primary comparison:
tools minus fresh control in official pooled SLU-F1, paired utterance-cluster
bootstrap CI95 lower endpoint above zero, and intent one-sided95 lower bound
above -1.44 percentage points. This margin is the frozen VAR-1 repeatability
half-width, not an independently justified practical-value tolerance.
Natural mixture is primary; equal-scenario weighting and every stratum
accompany it. A passing construction result requires a later matched
replication. Fixed control-then-tools order does not eliminate time effects.

Keep all episodes, including actions not reached, empty lookups, rejected
calls, finite completion, abstention and failed revisions. Inspect the whole
path: prior observable state, tool availability, actual arguments and source
IDs, returned versus previously visible evidence, review finding, Planner
decision, Solver change, normalization and delivery. Measure repairs, harms,
empty-entity false positives, nonempty omissions, and final intent. Local
Reviewer or Solver improvements cannot substitute for terminal benefit.
The initial three-candidate Solver contract remains; report the residual
candidate-miss ceiling instead of claiming this family recovers absent gold.

Full source-bound trajectories are reusable for later algorithm development;
this family is fixed-policy evidence, not a learned RL policy. Do not assign
a terminal scalar independently to every node and claim causal node credit.
Use frozen pre-action state and record action-not-reached outcomes in later
sampling designs. No policy update or memory learning occurs here.

Ceilings including smoke: 13,794 model calls, 55,176 fit endpoint calls,
2,516 valid native target lookups, 60,282 repeated speech seconds and 17
fit-inclusive utilization-integral GPU hours. These are structural ceilings,
not targets or a reintroduction of obsolete global caps. Every actual native
request, including tool schemas/history/results, is fitted by the same
request builder immediately before dispatch; downstream states cannot be
fabricated in advance. Preserve the full fit receipt and any overflow.
One complete official scorer job per full arm; smoke is engineering only.
Bind manifests, outputs and score hashes after both seals, before outcome
read. No partial scoring or selective roster filtering.

Stop on failure and preserve all artifacts. At most one root-diagnosed,
separately registered recovery; never automatically replay. Windows owns the
existing durable WSL queue; network and assistant credits are not in its
execution path. Freeze code through scoring, then integrate at the boundary.
No fresh DEV6570 or test13078, new weights, paid API, ASR or encoder contacts.
