# Separate conservative native preparation from exact contact admission

The candidate-recovery model-free preflight rejected a 27,248-token heuristic
Perception envelope against the 24,576-token slot. That envelope pools
worst-case downstream candidate, card and history blocks; it is not a realized
Perception request or a measured tokenizer receipt. No model, tokenizer or
scorer contact occurred. All eight preflight failures are preserved under the
candidate-recovery coordination directory. They are preparation failures,
not consumed generation attempts or a flight recovery.

Add the explicit shared preflight_budget_mode value
defer-to-native-contact-fit. Only a strict native episode, the default
four-bytes-per-token heuristic and valid registered native contact fitting
can use it. Record every original estimate and margin with estimate_only=true,
capacity_verified=false and enforcement=native-contact-fit-before-each-request.
Missing or incompatible actual fit configuration, a supplied counter, unknown
mode and non-native execution refuse. Omission preserves historical behavior.

This changes which preparation estimate blocks launch. It does not grant
model capacity, compact a request, change serving geometry, reduce completion
space or omit evidence. The existing exact request gate still measures each
actual immutable request under the exclusive lease, with its full speech
packet, role history and knowledge, before generation. Actual overflow stops
the flight. The native gate, request constructor and dispatch are unchanged.

Validation: first red regression, then 177 runtime/legacy-compaction/deferral
tests and52 native-fit/candidate/full-graph tests pass. These are model-free.
Enable the mode equally on the four candidate-recovery cells, re-pin changed
implementation/configuration preparation, commit and perform clean preflight
before independent WSL launch. No scientific threshold or roster changes.
