packets, frozen Qwen weights, sampling settings, resident decoder process and
official scorer. Use four 24576-token slots and a 256-token output ceiling per
request. NEW500 is primary; OLD500 and pooled DEV1000 are secondary.

The direct arm uses the existing direct-only shared controller and OpenJiuwen
executor. It receives the current speech and full legal task inventory, then
answers once. The shared phase harness adds its static direct-role control turn;
this is task instruction, not an intermediate model answer. It receives no retrieved knowledge, Perception state, experience
memory, review or analytical-tool result. A source snapshot retained as internal
runtime identity plumbing is not model-visible evidence.

The system arm uses the existing native OpenJiuwen role workflow. Perception
proposes one through three candidates. The source-bound knowledge lookup view
validates every raw object and retains the first occurrence of each legal
intent without padding; original native history remains unchanged. Solver
receives the complete released explanatory slot-card union associated with
those candidates, jointly selects one candidate and extracts the entities.
Reviewer invokes the native task-contract tool and reviews the proposed answer.
Planner accepts or requests one bounded revision. Solver alone owns the answer.

This comparison measures the aggregate system effect. It does not isolate the
effect of knowledge, role decomposition, candidate commitment, or review.
Additional model calls are part of the system and are measured, not equalized.
Do not add compute merely to match a budget.
