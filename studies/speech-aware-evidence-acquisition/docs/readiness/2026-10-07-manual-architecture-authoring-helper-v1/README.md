In a separate root analysis checkout, the resolution phase verifies the raw binding, exact clean worker HEAD/root, admission SHA, queue SHA, immutable intent bytes, registered plans, preparation receipts, population, policies, final config composition, analysis roster/strata and reader/analyzer source pins.
