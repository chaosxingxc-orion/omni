# Complete source material for context learners

The existing Training-Free GRPO adaptation and GEPA callback tasks reference
qualified complete-system trajectories. The source-material adapter makes the
full recorded episode available per candidate and input, without replacing the
learning algorithm or reducing full-node context to a short role-text preview.

## Entry and custody

Call `export_context_source_material` only through its public qualified entry.
It runs the existing exact whole-family READ, complete score, seal, reference,
cohort and timing qualification before opening semantic sources. Supply exactly
the registered candidate phase pins and their recorded clean frozen checkouts.
The manifest pins come from the already qualified family bindings. No caller
may substitute a root log, chat, another sample, historical comparator or test
feedback. Seed/A/A remain required for qualification but are not exported as
candidate learning material.

Reuse `verify_native_episode_source` and `export_system_trajectories`. Preserve
the complete phase result, original terminal output, related request/response,
tool and control records, and the original content-addressed trajectory index.
Retain failures and interrupted visits. Record no semantic omissions. Refuse
non-English scripts rather than silently dropping or changing source bytes; a
separate complete audited translation would be needed before model use.

Requalify the family after materialization and before publication. Save each
sample separately below the existing SystemSearchArchive and publish the final
index last. The input recipe, full-family commitment, source pins and every
material hash remain addressable. Partial files without a final index are not
learner inputs. Immutable archive writes prevent overwrite or silent replay.

## Actual scope

This is a model-free source projection, not a model actor, operating-system
sandbox, scorer, runtime knowledge provider or proposal authorization. Isolated
GPT-6.1 Sol actors still require prospective exact input/contact admission and
an input manifest. They may page the complete material as needed; a page is not
a license to omit uninspected evidence silently. Do not export this root chat.
The first real family is still running, its READ is unsigned, and no actual
answers, rewards or learning material were opened by this implementation.
