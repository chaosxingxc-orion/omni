# Source-verified TRAIN feedback enters the shared proposal runtime

The optional prepared_training_feedback configuration loads a sealed
training-proposal-contexts artifact and the pinned original source-binding list.
The loader rebuilds source authority from the prior frozen-core trajectories and
quality feedback, verifies the complete artifact and implementation fingerprint,
and requires exactly the active TRAIN construction cohort. The input is admitted
only for result_kind=artifact and artifact role training-feedback-proposal.

Use the initial ORG history for this prior execution context. Do not place it in
CONTROL instructions, present it as retrieved domain knowledge, or invent a
single-response source hash for grouped feedback. PreparedFeedbackStateArtifact
has its own strict version and provenance-derived identity, preserving the source
artifact, group feedback, construction roster and canonical model-context hashes.
Only the canonical model context enters the history content; source paths and
sample-binding metadata remain outside it.

The shared continuous phase runner passes the seed through the existing
EvidenceAgentController and OpenJiuwen executor. The actual per-wave request-fit
gate sees the same history content as the transmitted request. Runtime loading
requires that fit mode; a task-answer or native role-episode program cannot use this
proposal input. The bundle's phase-material receipt and ORG trace preserve the
input authority. An absent configuration retains historical request semantics.

The loader checks the declared English language and rejects non-Latin alphabetic
scripts; this is negative script validation, not automatic language identification
or translation. Its explicit maximum context byte count never silently truncates
feedback. A stale implementation fingerprint requires a new model-free preparation
artifact, not editing old pinned bytes.

Validation used synthetic sources and in-process transports only. It includes
pinned reconstruction, mutation/cohort/role refusal, true speech rendering,
legacy serialization parity, actual shared OpenJiuwen dispatch, source visibility
before CONTROL, and fit/send identity equality. The combined root runtime
regression selection passed 209 tests; focused native/proof integration passed
58 tests. No additional GPU contact was used for these checks.

This closes the input and execution seam. It is not a completed training-free RL
loop: task-specific proposal output contracts, provisional candidate evaluation,
admission and repeated system optimization still need their own registrations and
evidence. Unvalidated proposals are never promoted to memory automatically.
