# SLURP Top-3 commitment comparison: root prospective design

## Decision

Test whether postponing intent commitment lets the frozen main model use argument evidence to recover a provisional selection error. Use a common first-pass hypothesis source and give both successor branches the same speech, ordered hypotheses and compact TRAIN candidate contracts. Change only the branch instruction and its enforced final intent authority.

This is a controlled component comparison. It does not claim autonomous tool selection, an independent replication, a decomposition gain beyond extra inference, or complete-system superiority. The later agentic system must retain main-model-selected observation and knowledge actions.

This successor narrows the options in 2026-09-12-joint-intent-slot-hypotheses-root-design-v1.md. Fix exactly three ranked alternatives for this comparison. The earlier recommendation to allow one to three remains appropriate for a future adaptive policy; it is not used to let this mechanism test collapse to Top-1. A second correction is to keep this comparison closed to those alternatives. The existing open joint delivery rule remains available under its historical identity, but is not the closed arm.

## Source and matched branches

The source uses the shared one-contact phase-intent-hypotheses-only-v1 program and explicit response format slurp-intent-hypotheses-v1. It emits only candidates: three ordered distinct legal intent IDs, short observable distinctions and optional evidence-reference/unresolved-field lists. Rank is provisional, not a probability. The grammar exposes the exact canonical legal IDs; the prompt must define their spelling. Do not silently repair a colon or hyphen into an underscore after generation.

The source artifact has no task score. Preserve its raw response and separately bind runtime-added sample/schema/semantics plus the unchanged candidates. The artifact validator enforces the pinned TRAIN catalog, complete roster, canonical content and min_candidates=max_candidates=3. The model does not generate hashes or sample identity.

Both successors use phase-slots-given-intent-v1 on the same bound artifact through the shared runtime and OpenJiuwen executor. Both receive the same candidate contracts through the registered state view. These are observed TRAIN slot associations, not reference answers or declarations of mandatory/forbidden fields. Contract lookup is a controlled input for this component experiment; do not report that forced provision as an autonomous tool decision.

| Branch | Model responsibility | Registered final authority |
| --- | --- | --- |
| HARD_FIRST | Interpret slot meanings and extract supported entities while keeping the first-ranked intent | slurp-hard-first-hypothesis-delivery-v1 preserves source rank one and records attempted revisions |
| CLOSED_JOINT | Reconcile operation, target, entity roles and spoken values, then select one of the same three intents and bind its entities | slurp-shortlist-joint-hypothesis-delivery-v1 enforces shortlist membership |

Keep original speech available to both branches. A downstream model must be able to revisit evidence, not only paraphrase the first-pass answer. Neither branch may insert defaults or choose an intent just because its fields are easier to fill. Equal knowledge bytes do not guarantee equal attention; that is part of the tested decision policy.

Both rules share strict response validation and terminal saturation normalization. A refusal delivers no task answer and keeps the full attempted response in the generation bundle. A legal out-of-shortlist answer is recorded as a closed-arm violation, not silently credited as compliance. Illegal output, malformed entities, empty response and output saturation remain visible. Historical delivery behavior is unchanged.

This is a phase-specific output contract, not a hidden mid-flight cap change. Actual capacity checks must validate every request on the selected service. A failed capacity check blocks generation; a geometry fallback applies to the entire comparison and requires a new recorded binding before contact.

## Analysis and decision

The population is the historically exposed DEV1000 roster. NEW500 is the primary 500-row subset; OLD500 and pooled DEV1000 are secondary. Do not call any of them fresh or confirmatory.

Use the existing official SLURP scorer once per complete delivered manifest. Primary task quality is pooled-count SLU micro F1. Separately report intent, scenario and action accuracy, exact slot F1, row-mean SLU F1, natural-mixture and equal-scenario weightings, and every scenario. Use the frozen paired speaker-cluster bootstrap with 10000 draws and an explicit seed. Do not import an unrelated historical non-inferiority margin.

After release, diagnose first-pass Top-1 accuracy and Top-3 recall, rescue of wrong rank-one predictions, spoilage of correct rank-one predictions, and the partition: correct intent excluded, retained but not selected, selected with wrong entities. Measure supported entity binding separately from intent change. Report failed source contracts, branch refusals, out-of-shortlist attempts and attempted hard-first revisions.

For a closed shortlist, recall bounds the available intent opportunity; it is not realized improvement. Net intent change equals rescues minus harms divided by the full roster size. A clean source and a positive intent result still do not imply better slot or full-task quality. Do not promote on a selected subset or on improved candidate recall alone.

A positive paired primary interval is exploratory evidence requiring the inherited replication discipline. A negative or inconclusive result should identify whether the bottleneck is hypothesis coverage, knowledge discrimination, evidence acquisition or evidence use. It does not justify an unregistered candidate-width sweep on evaluation data.

## Subsequent system optimization

Use this comparison to locate a useful control decision, then return it to the native main-model loop. Learn training-free policies on isolated TRAIN trajectories for candidate width, which distinction to inspect, which knowledge view to request, when local speech tools are useful, whether to revise and when to stop. Keep compact validated correction rules as memory and stable task semantics as knowledge. Reward official task quality; tool use and longer reasoning are not rewards in themselves.

The current TRAIN catalog contains observed slot profiles and weak contrast information. It cannot resolve every operation or polarity distinction between intents sharing the same slots. A separate knowledge-value experiment must test concise choose/avoid boundaries and semantic role explanations, holding construction and consumption consistent. Do not attribute that future richer value to delayed commitment in this first comparison.
