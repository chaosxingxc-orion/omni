# Group-relative feedback and proposal-context readiness

The shared offline layer re-verifies complete finalized TRAIN reward sources, exact attempt identity, construction roster, projection, ordered cohort, response lineage, and native sufficient counts before producing feedback. It centers and population-standardizes each native quality dimension within each same-sample realized-trajectory group; zero variance yields zero. It preserves the separate intent, scenario, action, exact-slot, word, character, and combined sample-level word/character dimensions and never reduces them to one scalar reward or adds a cost penalty. The prepared proposal context contains prior own instructions, responses, selected supplied-evidence text, and numeric vector feedback while excluding reference targets, source custody paths, and source identifiers.

This layer describes paired realized trajectories. It does not estimate causal credit, prove matched scientific geometry, admit a memory, select a policy, or implement an optimizer. A registered source package must establish the scientific comparison, and a separate proposal, freeze, and disjoint selection lifecycle must decide how feedback changes behavior.
