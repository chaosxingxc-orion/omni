# Root-owned worker lease handoff

Run `python -m speech_aware_evidence_acquisition.core.flight.lease_cli --repo-root <repo> --data-root <data> --runtime-root <runtime> --lock-path <lock> --experiment <experiment> --cell <cell> --owner <owner> --expected-session-id <session> --token-output coordination/<token>` only from the root coordinator after selecting one declared campaign cell. The cell must permit the existing `worker` stage, be `ready`, have no flight dependencies, and match one resident serving session by its complete identity. The handoff creates a mode-0600 token beneath `$SPEECHRL_DATA_DIR/coordination/` without overwriting an existing file.

The coordinator stays in the foreground while the worker uses the token. It prints only the run, attempt, session, and token path; the secret token is never printed. Send the exact line `release` on standard input only after root has checked the worker's sealed result. EOF, an interrupt, an error, or any other text preserves the lease metadata and token for reconciliation. Only explicit `release` clears the token and releases the lease. The token grants lease custody to the existing attach-only worker path; it is not scientific authorization and does not bypass the worker's normal execution gate or preflight.
