## Exact latency boundary

The supported metric is admission-to-settled-workflow wall time. It includes the workflow's
internal waits, model execution, actual-request FIT, tool work, revisions and cleanup.
Pre-admission wait is reported separately. Roster preparation, final artifact persistence and
official scoring are excluded. Therefore this metric is not complete business end-to-end latency.

Keep original all-sample mean, first admitted sample, remaining-sample mean, first slot-count
admissions, later admissions and batch dispatch wall time separately. The first four samples
are not proven cold and later samples are not guaranteed warm. Batch wall time per sample is
throughput, not individual latency. Do not trim slow samples or select the exclusion after
observing results. Future summary/expansion calls inside the workflow count automatically;
work moved outside this boundary requires additional explicit metering.

The frontier is exploratory point-estimate selection, not a statistical superiority test.
Preserve registered A/A, intent protection, strata and measurement floors for conclusions.
A20-row result remains insufficient for a stable benefit claim. No positive gain is guaranteed.
