# F10 empty-contract representation pre-registration

Root registers the owner-approved F10 comparison before any F10 model,
tokenizer or official scorer contact. Run the existing four-row treatment
engineering proof, a fresh 625-row default-rendering control, and the matched
625-row empty-contract treatment. Use the shared four-node PLAN episode,
same frozen model and four-slot decoder-only geometry, precomputed speech
features, default twenty-example selection and 512-token output cap.

The sole intervention changes the empty third field of example values from
none to the literal fragment "entities":[]. It does not replace the whole
example with a JSON object. All 8,554 facet keys, source identities, targets,
priors and exclusions match the parent minus-R01 store. All 5,813 nonempty
values remain byte-identical; 2,741 empty values change. Selection remains
identical given the same query state because the shared ranker/fuser selects
by pinned vectors, facet/value identifiers, targets and scores, not this
rendered content. Later model-dependent state divergence is recorded rather
than forced away.

Freeze the exact estimators and candidate rules in
2026-09-25-slurp-stage3-f10-v1/analysis-specification-v1.json:
the natural-mixture pooled official SLU-F1 paired CI95 lower bound must exceed
zero, and the intent one-sided95 lower bound must exceed -1.44 percentage
points. That intent margin is the frozen aligned VAR-1 repeatability
half-width, not a clinical or independently elicited practical-value margin.
Report equal-scenario sensitivity, all strata, empty-target false positives
and nonempty-target false negatives. Do not promote a subgroup in place of
the full comparison. A passing construction result still needs replication.

The primary comparison is fresh empty minus fresh control. Existing PLAN and
PLANR scores are context only: their observed repeat difference makes reuse
of only the weaker historical arm inappropriate. The fixed order and service
identity are recorded as limitations. No policy is updated during either arm.

The complete generation ceiling is 13,794 contacts including the engineering
proof; fit endpoint ceiling is 55,176, repeated speech ceiling 60,282 seconds,
and fit-inclusive utilization-integral GPU ceiling 17 hours. These are
ceilings, not targets. Run one complete official scoring job per full arm;
smoke is structural proof and cost only. Bind sealed artifact hashes before
the paired analysis. Do not read partial answers or scores.

Preparation is model-free and may overlap the active VAR-2 recovery. F10 GPU
execution waits for the whole predecessor chain, including derived scoring.
On failure retain STOP and require root closure/release. Never automatically
replay. At most one separately diagnosed recovery can be registered.

No new evaluation roster, paid API, encoder, ASR, model weights or answering
model enters this comparison. Preserve all historical records and update the
English handoff at registration, launch and final decision.
