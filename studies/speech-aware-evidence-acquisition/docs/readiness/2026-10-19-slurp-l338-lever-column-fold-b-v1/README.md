Both levers run in ONE flight over the same 1,080 Fold B rows beside the in-chain twin and the delivering arm, as the branches of ONE level-2 Perception-branch group (`rails.supply_variants.parse_perception_sampling_variants`; receipt `saea-perception-branch-arms-v6` with a `sampling` field; `arm_visits` first).
