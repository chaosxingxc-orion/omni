finish. Root must verify complete operational members, no remaining driver,
generation/scoring/preprocessing work, and no competing coordinator activity.
Defer reclamation while another coordinator is active. Reclaim clean Linux file
cache only; retain the resident model, application allocations, KV cache and all
artifacts. Do not issue global sync, delete files, restart WSL or change host
settings. Record the exact config/cohort, process identities, completed-family
qualification, before/after host and WSL memory, action and outcome. Never claim
that the requested cleanup freed a particular amount before measuring it.
