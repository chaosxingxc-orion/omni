family identity, official scores, measured costs and root READ. Do not flatten
these panels into the former single-family K16 trial interface.

reference, and distinct source family/batch identities. It reuses the existing

measurements remain unavailable, and node correctness remains unmeasured.

cohort and input. A large shift between panel returns must not affect either
panel's normalization. Preserve raw official counts, terminal utility, timing and
separate cohort identities. Return no combined groups, pooled frontier, automatic
adoption or execution admission. Preserve the old single-K16 API's exact sixteen
member requirement and output format.

This is preparation only. No real K8 source feedback was read or exported for
this change. The active K8B worker and every original template remain unchanged.
No actor was invoked, allocation reserved, scorer replayed or runtime dispatched.
This boundary is not a complete learner integration or an authorization verifier.
