# Next-batch whole-system memory consumption baseline

The first source-valid three-record memory remains semantically unqualified.
This flight measures its actual use by the frozen core on the next four inputs,
rather than manually fixing its lessons or calling source validity learning gain.

Eight registered replicas form four matched learned/empty pairs. Each replica
runs the complete Perception, Solver, Reviewer and Planner graph. Only two
requests can be live. Both arms use the same memory-aware Reviewer capability
and prompt; all other roles, candidate-slot associations and knowledge stay
fixed. Seeds differ only in decoding parameters. The queue balances arm order.

The original four-input construction roster and the new evaluation-role receipt
have different runtime roles. The latter remains exposed TRAIN data and is
disjoint from the memory source; it is not confirmatory data. No test data opens.

Memory is immutable through this whole batch. The next update can consume all
four learned trajectories per input only after the full batch is scored. Empty
controls measure the memory intervention and are not automatically learner data.
The current four-input result cannot select a winner or support superiority.
Whole-roster evaluation and replication remain required.

Use the protocol and queue beside this document. Native capacity checks include
actual realized speech, role history, tools and full output reserve before every
contact. Failed fits stop; they never shrink outputs. Source validation, cached
supply preparation and offline tests do not contact the model.

Root will distinguish actual tool dispatch, record applicability, returned
guidance, Reviewer findings, Planner routing, Solver revision and final delivery.
Report unsupported feedback, harms and abstentions as well as corrections.
Keep entity counts, intent correctness and format separate. Natural-mixture and
equal-stratum summaries are descriptive at this size.

The intent-first versus entity-first proposal is a separate prospective system
action in the intent/entity design note. No such change enters these arms.
