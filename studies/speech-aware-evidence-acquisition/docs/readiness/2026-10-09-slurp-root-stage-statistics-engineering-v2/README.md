It does not authorize a quality read, select policies, add a comparison, or change official scoring. No actual results were inspected during engineering.

## Persisted projection

`solver_stage_statistics` has schema `saea-slurp-root-solver-stage-statistics-v1`, explicit root-only/no-export flags, endpoint semantics, the complete original stage source vector, numeric/custody rows, their content hash, and rederived aggregates. Every row retains the exact sample ID and runtime order, numeric `draft`, `pre_delivery`, and `final` metrics, revision states, and original request/response/visit/normalisation custody. It carries no model answer or reference text. The source vector binds config, protocol, split, run, attempt, ordered IDs, phase artifact, reference binding, and saved official-score hashes.

The unchanged builder defines the endpoints: first completed raw Solver after within-visit tools; selected delivered raw Solver before postprocessing; final delivery. They do not represent all intermediate visits or causal credit. Missing raw endpoints and unparsed entities remain unknown. Fixed-N diagnostic correctness uses the complete roster and contributes zero for unknown states, while known and unknown counts remain explicit. Unparsed intent/full failures retain existing semantics.

Aggregates retain intent/entity/full exactness, parse availability, native diagnostic sufficient totals, raw-model and postprocessing transition counts, strata, and Reviewer applicability. `combine_process` rejects partial/duplicate/reordered observations, inconsistent source/custody/parse/revision/native fields, text additions, changed row hashes, and non-rederivable or mistyped aggregates. Stage F1 values are checked using the existing arithmetic over native counts. This validation does not re-run the official scorer. Numeric endpoint values are generated from complete verified originals inside the existing derivative; a bare JSON row digest is not independent authority to supply new endpoint measurements.

The comparison JSON presents aggregate endpoints and stable-ID paired diagnostic sufficient counts only for the existing registered comparison groups. Its report labels endpoints and unknown counts. These counts add no confidence interval, selection rule, official corpus score or causal claim. Saved complete official scores remain corpus authority. Generic joint-policy mapping and adaptive-overlap admission are outside this patch.
