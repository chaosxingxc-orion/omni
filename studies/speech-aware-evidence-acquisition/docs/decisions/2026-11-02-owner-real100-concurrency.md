# 固定真实样本并发比较授权记录

本记录落实用户已有指示：使用真实数据共享名单，向上探索并发，优先实验效率与八卡有效任务利用率；服务和任务脱离 SSH，支持可信断点接续。无需追加人为签字流程。

本次先执行 C32，再按完整结果决定 C48/C64/C96；复用固定 100 条 TRAIN 记录，不读取 test 标签，不复制历史答案。两个 TP4 实例使用当前 48k 上下文、引擎 max_num_seqs=128、batch tokens=2048，模型预算为 4096 completion/3072 reasoning。客户端并发与服务启动 profile 分别记录，不改写 live 容器标签或历史 receipt。
