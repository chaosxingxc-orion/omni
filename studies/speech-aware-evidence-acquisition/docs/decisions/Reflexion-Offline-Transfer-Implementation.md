# Reflexion 离线迁移基线实现

本实现将 Reflexion 的文字反思记忆用于固定历史 TRAIN 轨迹的离线迁移。代码与针对性测试已完成；固定镜像最终版本203项测试通过（14.07秒），尚未运行真实 Reflexion 实验，也没有收益结论。注册表状态保留为 planned。

## 方法与比较口径

计划完整使用 51 组原始 TRAIN 轨迹，每组 4 条，共 204 条；原始经验父版本为空。每组进行一次反思调用，后续反思读取当前有界记忆。模型参数保持冻结，不增加 Curator，不计算相对优势，不执行 actor 重试。历史 actor 轨迹并未以新记忆为条件生成，因此不能解释为同一任务上连续试错的因果收益。

记忆上限为 48 条、每条 200 个 Unicode 字符、总计 10,000 字符。条目数量与单条上限同时生效，实际内容上限因此不超过 9,600 字符。容量设置用于与其他离线经验方法控制记忆规模，不代表等调用预算，也不是原论文复现。原论文常见小容量记忆设置与这里的 48 条容量有明显差异。

原论文参考：[Reflexion: Language Agents with Verbal Reinforcement Learning, v4](https://arxiv.org/abs/2303.11366v4)。实现设计依据已缓存的该版本正文；本次未重新在线核验论文内容。

## 数据和记忆契约

输入绑定完整原始轨迹、模型、策略、父经验、tokenizer、学习配置和所有历史费用。完整来源必须通过 native custody 核验；拒绝未知请求、外部组引用、重复轨迹以及 H2/test 反馈。所有失败或同分的组仍可反思，部分奖励不视为严格成功。

每次响应严格使用 saea-reflexion-memory-v1：reflection 可以为 null，或包含 content 和 trajectory_ids。拒绝额外字段、重复 JSON 键、空白或超长内容、外组或重复引用。null 仍记录真实调用成本。

运行时按内容散列确定条目身份，并使用插入顺序 FIFO。完全相同的内容不刷新位置，但追加来源记录。超出容量时整条淘汰，不截断内容；保留淘汰事件、前后记忆散列和全部历史来源。模型不能自行编辑记忆。独立审查仍须判断反思是否有证据支持，结构校验不等于语义成立。

## 共用执行与发布路径

方法通过 learning_strategy_job 的显式策略选择接入共享 prepare、verify、register、admit 和 Flight 路径，使用独立的 Reflexion 输入与运行时 schema。预注册只登记有限阶段身份和依赖；每个后续 prompt 从已观测前缀重建，再执行 native FIT 和生成。

共同运行时保留共享 guard、唯一租约、durable intent/response、全部历史成本和未知请求阻断。已知响应恢复使用原始 native/FIT/bridge/learner 证据，不能凭本地候选声明跳过核验。恢复不重新发送已观测请求；未知状态阻断后继调用。

候选发布逐条重演原始响应和 FIFO 更新，核对磁盘事件、来源、最终记忆和完整费用。候选的 semantic_review_required 为真，semantic_support_verified 和 deployment_accepted 均为假。消费端根据策略强制执行发布检查，删除候选中的审查标志不能绕过。

memory_order 用于后续反思的 FIFO 顺序；共享 H2 消费仍沿用共同经验条目的排序和渲染格式。H2 标签只用于评估，不用于更新。最终 H2 需完整 312 条，测试集 13,078 条保持隔离；当前尚无此方法的评估结果。

## 预算与边界

计划最多 51 次反思调用。按每次 49,152 context、4,096 completion cap、1,024 reserve 计算，输入分配上限为 2,245,632 tokens，输出分配上限为 208,896 tokens。这些只是预算上限，真实费用须从运行凭据读取并加回全部历史费用，不能按上限宣称实际成本。

生成过程支持已知前缀恢复，但共享发布消费适配器目前仍拒绝跨 attempt 恢复候选：完整 finalized ancestry 的发布消费尚未接通。空记忆候选也不能通过现有经验消费路径。实现完成不能替代正式测试、生产运行、独立语义审查或回归评估；秒/组、实例数、NPU 利用率、剩余时间和实际成本当前未知。

## 验证范围

针对性用例覆盖全失败来源、FIFO/重复/null、完整重演、首中末失败与未知不重发、精确 schema、来源篡改、预算和 context 阻断、共享 Flight 分发与 seal、真实 native/FIT 已知前缀恢复、进程退出、发布重演及 H2 消费检查。测试使用显式来源与模型传输替身，不能证明模型反思质量。正式镜像最终快照203项测试通过（14.07秒）；提交前16个源码/测试文件逐一比对送测字节。

## 完整H2接口补齐

共享候选消费层原已支持Reflexion，但H2上层身份与算法标签仍仅支持ACE。现已补齐两种策略映射，stage、derive、verify-stage与注册验证均绑定实际候选/release的方法；错误标注和更新哈希后的跨方法替换会拒绝。固定镜像83项相关回归通过（18.75秒）。这证明评估接口可用，不代表真实Reflexion候选或H2结果已经产生。执行说明见[共享H2流程](../operations/Learning-Candidate-H2-Runbook.md)。
