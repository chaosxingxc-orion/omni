# TFRL 算法对照与统一实施方案

状态：原文核对及实施设计；2026-11-02 更新。本页原位维护。TF-GRPO 已有本地适配实验；ACE、Reflexion、GEPA 尚未完成本项目对照，不能宣称复现成功或收益。

## 一、研究问题与当前证据

目标是在冻结 Qwen3-Omni 参数的前提下，通过系统轨迹与外部反馈改进知识构建、知识消费及后续决策，形成真正跨轮 RSI。研究对象不局限于一种命名为 RL 的方法：反思记忆、上下文适配和提示搜索是必要的非参数优化对照，但应准确标注类别。

现有最终融合有真实语义错误：新闻证据被用于外卖规则、calendar_set 被解释为 calendar_query。51 个有奖励差异组的 204 条轨迹没有严格成功答案，部分奖励差异不等于正例。冻结策略 H1 两次完整观测的严格正确变化为：93 条两次正确、19 条错→对、12 条对→错、189 条两次错误。SLU 从 66.5031% 到 68.8013% 是条件重复观测差异，不是算法收益，也不是独立统计难度估计。

因此当前优先研究：如何从失败和部分正确轨迹提取有效知识、如何防止融合丢失证据、如何使规则增益超过自然波动，而不是只增加 rollout 数。

## 二、参考算法及适用边界

| 方法 | 原始机制 | RSI 中的对照作用 | 必须保留的边界 |
| --- | --- | --- | --- |
| Training-Free GRPO | 同题多轨迹、组相对语义优势、经验 Add/Modify/Delete、多轮更新 | 当前参考基线；检验差异奖励能否形成有效经验 | 原文仅对有明确优劣的组提炼语义优势；同分组不伪造优势。密集奖励、证据分片与纠错属于本地适配 |
| Reflexion | Actor、Evaluator、自我反思与有界 episodic memory，反馈引导下一次尝试 | 低复杂度反思对照；研究全错但有具体反馈的样本是否能改进 | 原方法允许同任务反馈后重试；不能在 H2/test 获取标签后重答再冒充单次泛化。跨题经验迁移明确称本地适配 |
| ACE | Generator、Reflector、Curator；结构化条目、helpful/harmful 反馈、增量 delta、去重与精炼 | 优先新增的知识构建对照，针对整库改写的遗漏、过度压缩和错引 | 模型声称某条 helpful 不是因果收益；仍需真实配对/消融。离线学习后冻结评估，不能在完整测试过程中吸收标签 |
| GEPA | 轨迹反思驱动模块提示变异，按样本表现进行 Pareto 候选选择，必要时合并 | 研究知识消费及系统模块提示如何优化；也可选择知识构建提示模块 | 它是反思进化式提示优化，不是参数 RL。选择集用于搜索必须披露；一轮提示重写不等于复现完整 GEPA |

核对原文：TF-GRPO §3 的语义优势和经验操作；Reflexion §3 的反馈/记忆循环；ACE §3.1–3.2 的增量与 grow-and-refine；GEPA §3、Algorithm 1–2 的反馈集/选择集、变异和 Pareto 选择。论文其他任务的收益数字不作为本项目预期收益。

## 三、实施顺序与公平对照

### 第一组：知识构建对照

先固定 P/S、知识消费正文格式、召回与排序、输出预算和真实数据。比较：

1. 冻结 A0/lock，不更新知识。
2. 当前 TF-GRPO 本地适配，保留原始失败与成本。
3. TF-GRPO 加结构化证据纠错，作为独立消融，不覆盖原基线名字。
4. ACE 风格增量构建：先局部反思，再按条目合并、冲突处置和去重，不每次全文重写知识库。
5. Reflexion 风格离线反思记忆：同一 TRAIN 反馈，限制记忆容量；不使用评估标签重试。作为迁移适配对照，不混同原论文的同任务多次尝试指标。

共同的来源、数据隔离、预算与格式校验属于实验可信度要求。新增证据纠错不能悄悄加到所有方法后仍称原始基线；每个方法记录实际算法偏离。比较同一已采集轨迹的更新质量，是低成本机制诊断；跨轮学习必须另外执行当前采用策略的新 rollout，不能一直用旧 A0 轨迹冒充在线改进。

### 第二组：知识消费与系统模块搜索

构建候选通过第一组筛查后冻结知识，再加入 GEPA，初始只开放 Solver 的知识消费提示。后续按错误归因分别开放 key/value 描述、召回/排序或筛选；一次实验明确可变模块，保留父候选与合并来源。不能同时改知识、感知提示、解码与检索后将收益归于单一方法。

GEPA 的内部反馈/选择划分从 TRAIN 固定生成并版本化；不能将同一 query 或重复音频跨两侧。当前 H1 原始知识构建已接触全部样本，内部选择只是搜索信号，不能称未见验证。H2 继续完整开发筛查，所有方法共用冻结候选再配对评估，禁止把 H2 逐样本错误作为变异提示。改变数据角色时披露历史接触，不重命名后假装独立。

### 统一预算与指标

- 学习预算同时约束模型调用、输入/输出 tokens、最大轮数和卡时；预算用尽保留当前版本，禁止自动追加。数值写进任务配置，未完成计量前不宣称等预算。
- 先用同源轨迹做构建方法对照，再报告各方法完整闭环的真实总成本，含新 rollout、反思、候选筛选及失败请求。相同调用数不代表相同成本。
- 每个候选完整 H2 312 条共享 P、learned/lock 各一次 S，正常 936 调用；共享 P 适用于消费/构建对照，若改变 P 本身须改为完整系统配对并单独计费。
- 报官方 pooled SLU、Intent、修复/破坏、原始关系分组、配对区间、上下文长度、秒/条、卡数/实例数、ETA、调用/tokens。保持 SLU 至少 +1pp 且 Intent 不下降的筛查门槛；区间跨零不称稳定收益。
- 多方法、多轮选择引入选择偏差；记录全部候选和搜索预算。稳定结论需固定额外开发确认与方法冻结后的完整 13,078 条测试，不只选最好的单轮。

## 四、共享脚本与配置契约

唯一部署入口继续为 `configured_job_launch.py`，任务差异写 JSON。算法实现作为共享学习模块的 strategy；数据、来源、预算、原生 FIT、contact journal、评分、恢复、晋升与回退共用现有 Flight 路径。新增研究方法不能复制一套启动、账本或评分流程。

统一学习输入应包含：父策略/知识版本、固定 TRAIN 名单、轨迹和评分答案摘要、外部奖励、支持及反例、允许变更的模块、预算。统一输出应包含：候选内容、增量操作、逐项来源、保留/修改/删除理由、未解决冲突、实际成本、是否需要真实评估。学习输出与发布候选分离，模型说“有效”不触发自动晋升。

建议 strategy 名称：`tfgrpo_reference`、`tfgrpo_grounded_correction`、`ace_incremental`、`reflexion_offline_transfer`、`gepa_module_search`。这些是拟定接口，不代表五个算法已实现。实现完成才允许进入可运行注册表；未知或未实现 strategy 直接拒绝，不能静默回退到 TF-GRPO。无需为每种方法新增 Python 启动器。

当前纠错模块已补齐“引用的 intent/entity 与原始参考一致”的机械校验、有界纠错输入及共享执行适配，相关60项固定镜像测试通过（3.75秒）。真实token计量、原生失败来源核验和生产dispatch已接入共享执行链；实际prepare/register/admit已通过，真实一次纠错已完成并被拒绝：仍有news_query→takeaway_order、calendar_set→calendar_query及槽位缺漏，不进入H2，不追加纠错重试。纠错输入由55,506降为26,571 tokens，51组原始证据保留，查询标识/哈希/差异由CPU确定性补全，模型的意图/槽位断言仍验证；此项只防错引，不足以证明规则正确。完整语义支持审查、候选冻结和 H2 对照仍保留。ACE 局部 Reflector→Curator 两阶段、增量 ADD/MODIFY/DELETE、共享动态注册与原生 FIT、配置入口和已知响应恢复已实现；固定镜像208项相关测试通过（17.29秒，提交 `38526373`），首次真实反思1调用被拒绝，尚无候选或收益。恢复仅覆盖已验证的单个已消费前驱，未知请求继续暂停，不能宣称支持任意多层恢复链。其Generator复用历史TRAIN轨迹，明确标记离线适配，不称完整原论文复现；Reflexion 有界反思随后复用该证据接口；GEPA 复用同一轨迹/评估接口并新增真实候选搜索逻辑。

### 首个真实 ACE 实验：来源与分阶段边界

本地持久化原始 batch 已确认是 **51 个 contrastive TRAIN 组、每组4条，共204条轨迹**，不是174组。其51个组的顺序和逐组哈希与融合证据投影一致；原始 batch 文件 SHA-256 为 `46020fa689f7f0f42602910b2a24678a87aeaeeb66c9e75929589f8848793eb8`，对应来源 custody 同样记载51组、102项原始提议。51组均有奖励差异，但204条均无严格成功。174是上游全错组总数，其中123组同分；313是完整H1。这三种范围不能互相替代。正式 prepare 仍须从完整 sealed/native 来源重验，派生文档本身不授权生成。

真实 parent 是来源 batch 中的空经验库，哈希 `67cc7dda4ccd1958bbe085d9e956532c9fa992f09a2dda0f0cb88453a14ea15f`；不是失败融合生成的9条规则，也不是拒绝后的纠错候选。模型标识沿用来源 `bf16-thinking-real500-tp4-s128-v1`。本地普通配置快照为49,152上下文、4,096总输出、3,072 reasoning与1,024 answer reserve；这些仅证明存在该配置，生产 runtime identity、receipt及配置文件哈希必须重新绑定。不能将16,384输出的融合配置只改 ACE bounds 后称普通4,096配置。共享学习入口实际固定 temperature=0、seed=20261101，不能用普通任务配置的seed替代已注册学习配置。

| 阶段 | 固定证据与目的 | 当前可执行边界 |
| --- | --- | --- |
| CPU prepare | 重验51组来源、真实parent和模型配置；计量首个Reflector | 0模型调用；后续prompt等待真实前驱，不能提前宣布全部FIT通过 |
| 4组诊断，8调用 | 按已封存来源顺序固定前4组，只检查两阶段JSON、引用、增量和预算；不估计总体收益 | 当前无有来源证明的子集适配；`max_groups=4`会拒绝51组，不能截断或手改哈希。需要受验子来源后才可运行，不是当前ready任务 |
| 51组同证据对照，102调用 | 从同一空parent重建；同一204条轨迹和顺序，比较更新质量 | 当前实现支持完整51组；`max_groups=51`。若不扩展子集接口，可直接把此阶段作为首个有界机制诊断，不能报告已完成4组预试 |
| 174组扩展 | 纳入123个同分组，研究无相对优势时的反馈价值 | 需另建含全部真实轨迹和来源证明的输入；不得用现有51组重复扩充 |
| 313条及跨轮RSI | 完整TRAIN策略闭环与采用后新rollout | 需实际采用版本重新采集、反馈和更新；不等同于重放51组旧轨迹。每题单次观测不自动成为4轨迹组 |

当前 `max_groups` 是完整来源的拒绝上限，**不是抽样数或逐段停止位置**；每组固定Reflector→Curator两次调用，总调用由 `2 × len(source.batch.groups)` 推导。首个51组设计仅做一遍，固定 `max_findings=4`、`max_delta=4`、`max_items=48`、`max_characters=10000`；这些是预设容量约束，不是性能实测。每次输出4,096，额外上下文安全余量1,024（不同于输出内answer reserve），所以原生包装后的prompt上限44,032；51组分配最大输出417,792 tokens、最大输入4,491,264 tokens。这是最坏几何边界，不是预期消耗、等成本证明或ETA。首轮须另填真实资源配置和有限卡时预算；当前秒/组、ETA与卡时未知。单条增量链按依赖顺序串行，不能以102调用或8卡驻留推断8卡有效利用；可与独立有价值任务排队协同。

所有方法的同证据比较使用相同TRAIN原始反馈、parent、证据范围、消费格式和候选容量；历史TF-GRPO及融合预算不同，现有结果只作为带实际成本的历史对照，不能声称等预算。ACE不消费分片提议，但当前来源适配复用其验证链：继承312调用、6,128,213输入和774,237输出tokens，保留真实来源账本；方法新增成本单列，研究累计按请求身份去重。失败融合和纠错成本保留在整体研究账本，未作为ACE证据消费的请求不伪装成ACE新增成本。Reflexion离线迁移与GEPA提示搜索仍是独立待实现对照，不能把ACE接口通过测试写成多算法对照已经完成。

无效JSON、引用越界、语义错引、预算/FIT失败或未知请求均保留已知响应与真实成本并停止相应生成，不自动重试或截断。51组完整候选通过结构及独立语义审查后才能冻结并进入完整H2 312条配对；4组结果不作总体收益结论。最终13,078条测试持续隔离，不进入调优。

### 共享 H2 实施状态

策略中立的候选release消费校验、独立任务身份、完整312条共享P配对已经实现，正式镜像164项及15项补测通过（覆盖重叠）。消费时绑定独立语义审查、父版本、来源、原生FIT/响应和累计成本。真实候选仍缺失，恢复后候选释放及恢复代H2评分尚不支持；不能称真实完整闭环已完成。

## 五、当前任务与不确定性

H1 恢复评分和对错迁移统计已经完成；不重跑其模型调用。一次已准入纠错已完成并拒绝；当前优先部署冻结 Direct 完整测试基线，并接入 ACE 增量对照。固定非功能负责人持续小步改进环境预检、恢复、异步交接和观测，主线程保留研究判断。独立完整 A0 测试基线后继与纠错算法实现并行；候选无效时不跑昂贵 H2，更不能为了满载重复无价值实验。

当前没有需要新增授权的事项。ACE、Reflexion、GEPA 是否能在本项目带来稳定提升仍未知，按上述对照验证。LoRA 系统级 RL 仍属第二阶段；不将这些参数冻结方法等同于 verl 参数训练。

## 首个 ACE 真实失败与后续比较（13:34 UTC）

已实际生成1个反思响应，输入2,917/输出3,963 tokens，81.799秒。空parent下生成重复的非知识ID，校验拒绝；无Curator输出、无候选、无H2指标。冻结失败证据，不移除非法字段后冒充成功，不盲重试。独立审查同时检查反思的事实与奖励解释，协议修正须新版本和新实验身份，完整保留旧成本。

共享H2接口正式测试已闭合（164项通过及15项补测；有覆盖重叠），真正候选仍待生成和审查。Reflexion离线迁移的具体实现设计并行进行；它须在逐条反馈→有限反思记忆上与ACE区分，并披露偏离原论文的离线迁移假设。GEPA仍作为冻结知识后的消费提示搜索对照，不把尚未实现的算法写成可运行任务。
